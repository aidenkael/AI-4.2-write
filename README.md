# AI-Write 小说创作工作台

AI-Write 是一个辅助长篇小说创作的工作台。作者在此管理原始素材、积累参考作品知识、进行原创小说的规划与写作。工作台中的 Agent 和 Skill 负责后台复杂度，作者只需关注创作本身。

## 目录结构

```
E:\AI-Write
├── 00_项目控制/    ← 系统说明：工作台当前状态与长期原则
├── 01_原始素材/    ← 未经 AI 加工的原始参考来源（epub/txt/pdf 等）
├── 02_原著蒸馏/    ← 参考作品的结构化知识（BKP/evidence/knowledge）
├── 03_作品工程/    ← 原创小说：设定、规划、正文（真正的创作发生在这里）
├── 04_写作知识库/  ← 经多作品验证的长期写作知识
├── 05_Skills与自动化/ ← 工作台后台能力（作者通常不需要手动进入）
├── 06_工作区/      ← 临时运行空间（任务结束即可清理）
├── README.md
├── AGENTS.md
└── .gitignore
```

## 作者日常主要看

- **01_原始素材**：你收集的参考原著和资料
- **02_原著蒸馏**：工作台从参考书中学到的知识
- **03_作品工程**：你自己的小说作品（真正的创作在这里）
- **04_写作知识库**：经过验证的长期写作经验

## 系统目录说明

- **00_项目控制**：工作台当前状态、原则（Agent 维护）
- **05_Skills与自动化**：后台能力实现（Agent 维护）
- **06_工作区**：临时空间；有长期价值的产物提升到对应业务目录，其余任务结束后删除

## 核心原则

- 真正创作发生在 **03_作品工程**
- 参考知识（BKP）服务创作，不替代创作
- 作者控制方向和重要取舍，后台负责记忆、检索和机械维护
