# 边界、反例与不确定性：一九八四

> 从 50 条 BOUNDARY 条目与 Deep Dive 反证中归纳。分为全局性边界与章节级边界两层。

---

## 全局性边界（影响整体 BKP 可用性）

### 译本限制
- 全部 682 条证据基于**上海译文中译本**。文体类观察（句长、用词、节奏、新话术语修辞）仅对该译本有效，不可外推至奥威尔英文原文。
- 语言双值化（如"鸭话""黑白"）的具体修辞效果受译者选择影响。

### 知识等级
- 29 条 MECHANISM 与 6 条 Deep Dive Pattern 均为 **单书 Pattern Hypothesis**。
- 未经跨书验证与真实创作测试，**不得升级为普遍写作规则**。
- 本作是反乌托邦类型极端样本，其结构特征（控制层级升级、零保留结局）依赖长篇体量，短篇/中篇迁移需重新验证。

### 视角限制
- 全部信息控制场景均经**温斯顿视角**呈现。体制决策层无独立场景，奥勃良自述本身是审讯策略，不可当作体制自画像的客观证据。
- 奥勃良"目光交换"是否真实发生，文本自身即存疑（ch_0001），据此的人物关系结论应降权。

### 无产者双重书写
- 无产者被写为"不受控"（多数无电幕、无灌输）同时又被彩票/色情工业/写诗器歌曲操纵。两条线索文本**未调解**，观察必须并列保留，不得取一。

### 适用范围声明
- 适用：反乌托邦/监控悬疑/组织权力题材的长篇。
- 不适用：不得把 P1–P6 当作普遍写作定律；不得用于断言"监控题材必须这样写"。
- 未验证于非政治题材（爱情/家庭/奇幻）前不外推。

## 章节级边界选录（50 条中的关键条目）

### 认知不可靠性

- ch_0002：梦境内容只经温斯顿转述，奥勃良声音的"认出"过程自述模糊，不可作为情节事实使用。
- ch_0003：大量内容为梦境与模糊回忆，其中"事实"均为温斯顿主观材料，不可当作作品世界确定设定引用。
- ch_0004："很可能没有一双鞋子被生产"为温斯顿的推断而非文本确认事实，引用时需标注为主观判断。
- ch_0015：母亲-妹妹记忆来自三十年后的重建，细节（巧克力、地铁）可能受电击制造的假记忆污染。

### 单点展示限制

- ch_0004：体制流程为纪录司内部逻辑的单点展示，不可外推至真理部全部门或整个党的决策机制。
- ch_0005：赛麦对新话的阐述是其角色言论，应视为作品内立场而非作者论述；文本未提供反方声音。
- ch_0017：禁书《理论与实践》由奥勃良参与合写，其内容（尤其关于无产者）本身是控制工具，不可当作作品真相引用。

### 人物定性来源

- ch_0002：派逊斯形象由叙述者直接定性（"头脑愚蠢"），属于叙述者判断而非场景展示，据此的人物技法结论需降权。
- ch_0016：奥勃良"电幕关闭二十分钟"为其单方面声明，不可验证，入会场景的安全性建立在不可证伪的前提上。

### 文体/形式

- ch_0017：章中书为虚构文献，其论证（寡头集体主义理论）在作品内的功能不等于其论证的正确性。
- ch_0024：附录《新话的原则》以过去时写成，暗示新话最终被取代，但这层含义来自语法形式而非叙事明确声明。

## Deep Dive 反证（信息控制维度）

1. 全部信息控制场景均经温斯顿视角呈现；体制决策层无独立场景，奥勃良自述本身是审讯策略（ch_0020）。
2. 无产者被写为“不受控”同时又被彩票/色情工业操纵，两条线索文本未调解（ch_0007）。
3. P1–P6 均为单书假设；本作是反乌托邦极端样本，“控制层级升级”结构依赖长篇体量（ch_0001）。
4. 文体层观察受上海译文译本限制，语言双值化的具体修辞效果不可外推至英文原文（ch_0005）。

## Deep Dive 反证（情绪/恐惧塑造维度）

1. 全部恐惧场景经温斯顿视角呈现，读者无法独立验证“恐怖”强度；电击后的爱慕可能部分源于药物/生理作用（安瓿注射），据此的“恐惧→依恋”结论应保留生理因素解释（ch_0020）。
2. P7–P12 均为单书假设；本作恐惧依赖全景监控设定与长篇体量，短篇、无监控题材迁移需重新验证（ch_0001）。
3. 生理词汇的选词与节奏受上海译文中译本影响，英文原文的身体修辞可能不同（ch_0005）。
4. 预告式恐惧（P8）与信息控制 P1/P3 相互重叠：不确定性监控与抹除过程化本身就是恐惧装置，两条 Pattern 线不可计数为两套独立机制（ch_0008）。

## Deep Dive 反证（结构与失败结局维度）

1. 全部结构观察基于上海译文中译本；章中书/附录的文体效果与“过去时暗示”受译本与编辑影响（ch_0024）。
2. P13–P18 均为单书假设；零保留结局与“宣布式失败”依赖长篇体量，短篇/中篇迁移需重新验证（ch_0001）。
3. P14/P15 与信息控制 P5（控制层级升级作为情节引擎）相互重叠：同一批第三部事件既支撑“控制升级”也支撑“希望落差/分层投降”，两套 Pattern 是同一证据的不同抽象层，不得计数为两套独立机制（ch_0020）。
4. 附录“新话最终被取代”属于文体形式推断（过去时/学术体），文本未明确声明，引用时必须区分 FACT 与 INFERENCE（ch_0024）。
