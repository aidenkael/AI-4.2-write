# 作品地图：三体（book_0065）

> 由 42 章逐章 MAP 整合而成。三册结构对应：第一部（0001–0035）地球往事；第二部（0036 单章）黑暗森林；第三部（0037–0042）死神永生。
> 章节标题与行号以 SourcePrepare PASS 拆分文件为准（0036 单章 10115 行，承载整部《黑暗森林》及尾声/后记）。

## 三册宏观结构

- **第一部（0001–0035）地球往事｜发现与锁死**：科学边界与学者自杀谜团 → 红岸往事（叶文洁）→ 三体游戏（文明试错史）→ 地球三体组织 → 两个质子锁死科学 → 古筝行动 → "你们是虫子"与反击姿态。
- **第二部（0036）黑暗森林｜推导与威慑**：叶文洁给出宇宙社会学公理 → 面壁计划 → 咒语与冬眠 → 章北海逃亡 → 水滴毁灭舰队 → 黑暗战役 → 罗辑推导黑暗森林 → 摇篮威慑（"住手！"）→ 威慑纪元。
- **第三部（0037–0042）死神永生｜继承与坠落**：阶梯计划（云天明赠星/人脑）→ 执剑人交接与威慑失败 → 引力波广播与文明暴露 → 童话情报与黑域推导 → 星环城与程心否决光速飞船 → 维度打击与太阳系二维化 → 小宇宙与回归运动。

## 第二部：黑暗森林（0036 单章）

- **尾声·遗址**：叶文洁临终"这是人类的落日"；后记（作者自述零道德宇宙命题）。
- **序章**：褐蚁视角；叶文洁墓前给出宇宙社会学公理；伊文斯-三体思维透明双线对话。
- **面壁计划**：四位面壁者；萨伊"我们怎么知道您是不是已经在工作了"；罗辑被指定。
- **咒语与冬眠**：罗辑发送 187J3X1 恒星坐标后冬眠；苏醒被告知"笑话"。
- **章北海线**：陨石谋杀航天要人；劫持"自然选择"号"前进四"（"为人类文明保留一粒种子"）。
- **水滴**：丁仪"傻孩子们，快跑啊！"；水滴摧毁联合舰队；"毁灭你，与你有何相干"。
- **黑暗战役**：星舰地球资源死局；"终极规律"号突袭；"蓝色空间"号幸存。
- **黑暗森林推导**：罗辑香烟演示；"宇宙就是一座黑暗森林"。
- **摇篮威慑**：雪地工程+手枪对准心脏；三体"住手！"；威慑纪元开始。
- **尾声**：罗辑与监听员对话（爱作为变量）；蚂蚁在墓碑攀爬（"如果我做错了什么，对不起"）。
