## 一、收口说明（244 → 17）

- **跨章重复优先保留**：至少出现在两个不同时代/故事线/文明视角中，或虽只出现一次但承担全书结构功能的机制升为正式条目。
- **同质合并**：例如"摇篮系统/反触发威慑/威慑度曲线/黑域声明"合并为威慑工程化；"倒计时胶片/宇宙闪烁凌晨/舰队四百五十年/水滴九分钟"合并为期限引擎；"审讯笔录/解密档案/童话/歌者视角"合并为多文体并置。
- **降为局部观察（不进正式机制集）**：
  - 温情的叙事呼吸（齐家屯饺子、人参、圣诞问候）——功能性单章手法，跨章样本不足以单列；
  - 失明作为感官滤镜（0042）——单章强效果，迁移面窄；
  - 桌面演示计划（雪茄演示古筝、烟头演示黑暗森林）——并入"高概念的教学化具象"；
  - 首尾呼应的旁观者（褐蚁/蚂蚁）——并入"虫子隐喻与反讽"。
- **与《一九八四》的关系**：本轮机制全部由《三体》自身证据收敛，不把上一本的 15 条改名复用；两书共有且确实重复出现的通用机制（如"阶梯式压力升级""权威解释被证伪"）在 G2 跨书观察中单独说明，不在此强行去重。
- **本轮未发现**以下低质量抽象：纯"章末放悬念"式空泛条目、"制造冲突"式无结构建议。244 条原始机制均绑定具体场景、信息结构或物理设定。

## 二、正式机制（17 条）

### PATTERN-01｜公理化宇宙模型（理论图景驱动全书）

- 解决的问题：科幻世界观需要"为什么世界是这样"的底层答案，直接说明显得像说明书。
- 核心机制：先给出几条不证自明的公理或一个可推导的模型，让全书的冲突、威胁、反转都从这套理论里长出来；理论推导本身成为情节。
- 文本中如何运行：叶文洁给出宇宙社会学两条公理（生存是第一需要；文明扩张而物质守恒），罗辑用"猜疑链+技术爆炸"推出黑暗森林；威慑博弈学用"威慑度>80%"解释执剑人制度；"光速降到16.7km/s"推出黑域；"宇宙规律是武器"解释维度打击。
- 跨章支持：chapters/0036.md#L9359-L9470；chapters/0036.md#L231-L243；chapters/0038.md#L437-L459；chapters/0039.md#L2058-L2078；chapters/0042.md#L285-L363。
- 反证 / 不成立位置：黑暗森林理论本身在书内长期"无法证实也无法证伪"（广播纪元对它的质疑），说明公理模型可以带病运转——读者先接受其叙事效力，科学效力留白。
- 中间因果链：公理 → 角色推导 → 读者跟着推导 → 后续每个事件都能被这套理论解释 → 世界观自洽感自动成立。
- 读者经历：从"记住一个比喻"到"自己推出一句结论"，获得参与推导的快感。
- 必要前提：公理要足够简单（可复述），推论链条要可复核（数字、因果）。
- 失败模式：公理本身太复杂，读者记不住；或理论只用于解说，不参与情节推进。
- 可迁移部分：给作品配一个"一句话世界观内核"，让主要冲突都能由它推导。
- 不可照搬部分：黑暗森林的具体公理与概念名。
- 置信度：高（四条独立公理/理论跨五章承担结构功能）。
- 能力地图标签：C16 世界质感 / C10 信息控制。
- 最小迁移测试：写一个 3 千字短篇，只给出两条公理，让主角在冲突中推导出结局。

### PATTERN-02｜极小-极大反转（微小物承载文明级力量）

- 解决的问题：宏大威胁容易空泛；读者需要"亲眼看见"威胁的尺度。
- 核心机制：让一个物理上微不足道的东西（质子、探测器、纸条）承载决定文明存亡的力量，用"几乎等于什么都没有"的贬低引出"它是一把锁"的反转。
- 文本中如何运行：两个质子锁死人类科学；一个三米五的水滴摧毁两千艘恒星级战舰；一张八厘米纸条让太阳系降维；一个智子监视整个地球。
- 跨章支持：chapters/0031.md#L80-L90；chapters/0034.md#L264-L266；chapters/0036.md#L7765-L7781；chapters/0041.md#L276-L480。
- 反证 / 不成立位置：水滴的"绝对光滑"先被误读为和平信号——极小-极大反转的生效前提是"外观无害"，若威胁一开始就显得凶恶，反转不存在。
- 中间因果链：贬低其尺寸 → 展示其功能 → 读者重新评估"大小"的意义 → 尺度感被反复重置。
- 读者经历：先"就这？"后"竟然"。
- 必要前提：微小物必须有一个可解释的"为什么小却强"（强互作用力、高维、相对论质量）。
- 失败模式：只强调"小"和"强"的对比，不解释机制，读者会觉得是硬设定。
- 可迁移部分：任何"不起眼的物件决定全局"的设定都可先贬后扬。
- 不可照搬部分：质子/水滴/纸条的具体设定。
- 置信度：高（四个独立场景使用同一结构）。
- 能力地图标签：C16 世界质感 / C10 信息控制。
- 最小迁移测试：让一个玩具大小的装置决定一座城市的存亡，先写旁观者的轻视，再写其启动。

### PATTERN-03｜高概念的教学化具象（日常物演示抽象原理）

- 解决的问题：硬核设定若直接解释，读者掉队；若全删，世界失去深度。
- 核心机制：把抽象概念（物理规律、计算机原理、光速、混沌）翻译成一件可看、可摸、可重演的日常物或仪式，让读者在"看见"中理解。
- 文本中如何运行：搬台球桌演示"规律不随位置变化"；三千万士兵举旗演示与门/或门；香烟过滤嘴的吸附面积类比维度折叠；两根烟头演示两个文明的猜疑链；维德用一截头发演示曲率驱动。
- 跨章支持：chapters/0002.md#L40-L66；chapters/0018.md#L76-L132；chapters/0031.md#L114-L130；chapters/0036.md#L9383-L9417；chapters/0040.md#L439-L461。
- 反证 / 不成立位置：教学场景若拖得太长会中断剧情，书内此类演示几乎都控制在两页内，并以角色反应收束。
- 中间因果链：抽象概念 → 日常类比 → 读者"哦原来如此" → 概念此后反复出现时不再需要解释。
- 读者经历：先困惑，再被类比点亮，之后能自己复述概念。
- 必要前提：类比必须与概念结构同构（不只是比喻漂亮）。
- 失败模式：类比漂亮但结构不对，读者记住类比却理解错概念。
- 可迁移部分：每个关键设定配一个"口袋类比"，并让类比在后续章节回指。
- 不可照搬部分：具体道具。
- 置信度：高（五个独立场景使用同一教学结构）。
- 能力地图标签：C16 世界质感 / C15 文学功能。
- 最小迁移测试：把"量子纠缠"用两个同色手套讲给读者，并让角色在情节中引用它。

### PATTERN-04｜超自然的技术回收（神迹由后期物理设定解释）

- 解决的问题：前期神秘事件若始终不解释，读者失去信任；若解释太早，悬念过早泄气。
- 核心机制：让早期所有"神迹"（倒计时、宇宙闪烁、魔法）在后期由同一个物理设定统一回收，形成"原来全是同一个原因"的闭合感。
- 文本中如何运行：汪淼的倒计时与宇宙闪烁在智子一章被解释为智子感光/展开；1453 年的"魔法"是四维碎块；"纸条"是二维空间的封装；黑域/曲率由童话信息推导。
- 跨章支持：chapters/0034.md#L368-L376；chapters/0037.md#L185-L189；chapters/0041.md#L512-L518；chapters/0039.md#L1796-L1804。
- 反证 / 不成立位置：针眼画师的画作为"无法解读的隐喻"直到终局才被揭示为维度打击——回收可以延迟到最后一章，但必须在世界观内自洽。
- 中间因果链：神迹出现 → 读者积累疑问 → 后期给出统一机制 → 读者回读前文获得"我早该想到"的快感。
- 读者经历：从"信还是不信"到"原来可以这样解释"。
- 必要前提：回收机制必须与全书其他设定一致，不能每个神迹各配一个解释。
- 失败模式：解释太晚，读者已放弃；或解释太技术化，冲淡神秘感。
- 可迁移部分：长篇悬疑/奇幻可设计"所有异常同源"的回收点。
- 不可照搬部分：智子/二维空间的机制。
- 置信度：高（至少四条独立神迹线被同一套设定回收）。
- 能力地图标签：C10 信息控制 / C17 Canon。
- 最小迁移测试：在前三章埋三个互不相关的怪现象，在终章用一个设定同时解释。

### PATTERN-05｜双文明镜像结构（同一事件在两端对称发生）

- 解决的问题：对抗双方各自的行为动机难以同时让读者理解。
- 核心机制：让同一动作或同一事件在双方文明中各发生一次（接收信号、按下发射键、面对警告、做出选择），读者从对称中自动对比两边的处境。
- 文本中如何运行：叶文洁按下发射键与三体监听员按下发射键对称；"不要回答"警告在两端各被违背/执行一次；人类与歌者都在"清理"与"被清理"之间。
- 跨章支持：chapters/0033.md#L62-L66；chapters/0024.md#L76-L86；chapters/0036.md#L263-L391；chapters/0041.md#L3-L158。
- 反证 / 不成立位置：镜像要求两边的规则可类比，一旦一边的科技或道德逻辑相差过大，对比会失衡；书内以"思维透明 vs 思维不透明"保证对称成立。
- 中间因果链：事件在 A 端发生 → 读者看到 A 的动机 → 同一事件在 B 端发生 → 读者自动比较 → 双方各自的可理解性同时建立。
- 读者经历：像同时看两个棋盘上的同一步棋。
- 必要前提：两端必须有可比的处境（资源、信息、选择空间）。
- 失败模式：只镜像动作不镜像动机，读者只看到"巧合"。
- 可迁移部分：敌对双方各写一场结构相同的戏，让读者自行对比。
- 不可照搬部分：具体事件。
- 置信度：高（三组独立镜像跨章成立）。
- 能力地图标签：C01 故事发动机 / C06 POV。
- 最小迁移测试：让正反双方在各自章节里做同一个决定，结尾让读者比较两者对错。

### PATTERN-06｜信息分级与延迟披露（知情权即叙事权力）

- 解决的问题：读者需要悬念，但作者不能一直不给信息。
- 核心机制：把"谁知道什么"做成故事的分层：主角知道的、组织知道的、敌方知道的、读者知道的各不相同；信息按梯级释放，每次披露都重新定义局势。
- 文本中如何运行：汪淼与会者共享"出事了"却不知敌人是谁；大史把分散事件串成"一个后台"；潘寒逐层确认"游戏是真实的"；会面时用三盏灯实时标记谈话安全等级；杨卫宁转移频率等疑点静默铺设。
- 跨章支持：chapters/0001.md#L84-L88；chapters/0011.md#L100-L120；chapters/0019.md#L44-L62；chapters/0031.md#L32-L34；chapters/0039.md#L436-L470。
- 反证 / 不成立位置：信息延迟到读者失去耐心时失效；书内以"每层披露都带来新的更高级谜题"维持节奏。
- 中间因果链：信息差 → 追问 → 部分答案 → 新的信息差 → 读者持续向前。
- 读者经历：像在雾中看灯，先见轮廓再见面目。
- 必要前提：每一级披露要解决旧问题并制造新问题。
- 失败模式：披露节奏过慢，读者已猜出答案；或披露过快，悬念断供。
- 可迁移部分：给主要角色建立"知情等级表"，按等级释放信息。
- 不可照搬部分：具体的信息项。
- 置信度：高（跨六章的多层信息结构）。
- 能力地图标签：C10 信息控制 / C11 连载留存。
- 最小迁移测试：写一个秘密组织场景，让主角、读者、组织各知其一，结尾合并。

### PATTERN-07｜威慑的工程化与人格化（机制+威慑度）

- 解决的问题：威慑/要挟容易写成嘴炮；读者需要看到"它真的会执行"。
- 核心机制：把"同归于尽"变成可操作的技术系统（触发条件、反触发、心跳监测），再把系统绑定到个人（威慑度曲线），让威慑同时拥有机器与人两个支点。
- 文本中如何运行：罗辑的摇篮系统用心跳维持反触发；执剑人制度用威慑度曲线（蚯蚓/眼镜蛇/百分百）评估候选人；维德用反物质子弹与"我遵守诺言"建立另一种威慑；黑域把"安全声明"变成可计算的低光速黑洞。
- 跨章支持：chapters/0036.md#L9731-L9737；chapters/0038.md#L437-L459；chapters/0038.md#L1309；chapters/0040.md#L471-L479；chapters/0039.md#L2110-L2116。
- 反证 / 不成立位置：威慑系统越精巧越怕"不可预测的人"——程心当选执剑人恰因威慑度低，说明人格化既加固系统也制造漏洞。
- 中间因果链：威慑目标 → 触发机制 → 绑定个人 → 读者评估"这个人会不会按" → 威慑的可靠性成为悬念。
- 读者经历：先信系统，再开始怀疑掌握系统的人。
- 必要前提：触发条件必须具体（心跳、信号中断、按钮顺序），不能是"到时候再说"。
- 失败模式：系统太完美，威慑变成道具；或人物太可预测，悬念消失。
- 可迁移部分：任何"威胁"都给它一个可验证的触发装置。
- 不可照搬部分：摇篮/威慑度的具体设计。
- 置信度：高（三个独立威慑系统跨章成立）。
- 能力地图标签：C09 Scene Turn / C10 信息控制。
- 最小迁移测试：让角色用一个"心跳停止即引爆"的装置威慑对手，写读者是否相信他会按。

### PATTERN-08｜期限与倒计时的悬念引擎（可数时刻制造等待）

- 解决的问题：事件何时发生不明确时，紧张感无法积累。
- 核心机制：给重大事件一个可数的倒计时或期限（小时、分钟、光年、世代），读者可以替角色数时间，等待本身就变成叙事。
- 文本中如何运行：幽灵倒计时从 1200 小时递减；宇宙闪烁预约凌晨一点；三体舰队"四百五十年后到达"；水滴"九分钟到达地面"逐次播报；移民期限一年；1890 万年的时间膨胀。
- 跨章支持：chapters/0003.md#L38-L48；chapters/0006.md#L40；chapters/0029.md#L16；chapters/0038.md#L1063-L1177；chapters/0042.md#L655-L787。
- 反证 / 不成立位置：倒计时若反复使用会疲劳，书内在不同层级换尺度（个人→行星→文明→宇宙）维持新鲜。
- 中间因果链：给出时刻 → 读者开始数 → 每个场景都自动携带倒计时 → 事件发生时张力封顶。
- 读者经历：替角色着急，即使角色无动于衷。
- 必要前提：倒计时必须与读者关心的后果绑定。
- 失败模式：倒计时太长，读者麻木；太短，来不及铺垫。
- 可迁移部分：任何"已知终局"都可配一个可数的时刻表。
- 不可照搬部分：具体数字。
- 置信度：高（五个不同尺度的倒计时跨章成立）。
- 能力地图标签：C11 连载留存 / C10 信息控制。
- 最小迁移测试：给短篇一个精确到分钟的事件时刻，写主角在中段的等待。

### PATTERN-09｜时间跳跃与纪年骨架（冬眠/纪年/时间膨胀做尺度工具）

- 解决的问题：文明级故事的时间跨度远超个人寿命，如何让读者感受"漫长"。
- 核心机制：用冬眠、纪年标签、时间膨胀让同一人物跨越百年千万年，历史加速与个人体验的对比自动产生。
- 文本中如何运行：罗辑冬眠两百年后见证新世界；"危机纪元/威慑纪元/广播纪元/掩体纪元"分段；程心在 1890 万年后才读到留言；低光速下绕行星一圈即千万年。
- 跨章支持：chapters/0036.md#L6106-L6117；chapters/0037.md#L197-L1185；chapters/0042.md#L655-L787；chapters/0042.md#L781-L787。

### PATTERN-10｜资源死局逼出道德选择（一部分人死或所有人死）

- 解决的问题：道德困境直接抛出会显得说教；需要让读者先认同"别无选择"。
- 核心机制：把角色群体放进一个无法回避的资源死局（燃料、粮食、名额），让"谁活"变成可计算的问题，再让角色在其中做选择。

- 反证 / 不成立位置：死局一旦有外部解法，道德张力消失；书内刻意把解法都封死（燃料耗尽、技术锁死、时间不足）。
- 中间因果链：资源约束 → 计算生存数 → 道德选择 → 选择留下后果 → 读者自行裁决。
- 读者经历：先算数，再心寒，最后不得不评判角色。
- 必要前提：约束必须具体可算（多少燃料、多少名额）。
- 失败模式：死局设置太简单，读者能找到逃生门；或选择者毫无犹豫，失去张力。
- 可迁移部分：群体困境用"可计算的资源缺口"呈现。
- 不可照搬部分：具体资源与数字。
- 置信度：高（五个独立死局跨章成立）。
- 能力地图标签：C03 人物心理 / C09 Scene Turn。

### PATTERN-11｜多文体并置（审讯/档案/童话/外星视角）

- 解决的问题：长篇小说单一叙事文体容易疲劳，大段信息难以进入。
- 核心机制：把关键信息装进不同文体（审讯笔录、解密档案、庭审记录、童话、外星吟唱、回忆录），每种文体自带节奏与信任度。

- 最小迁移测试：把一个事件分别用审讯笔录、日记、报纸三种文体各写一遍，看信息差异。

### PATTERN-12｜格言化世界观（一句话浓缩宇宙观）

- 解决的问题：世界观再宏大，读者最后记住的是几句话。
- 核心机制：把复杂理论压缩成人物口中可复述的格言或口号，让读者凭句子记住全书，并让句子在后续被反复回指。

- 读者经历：从"读句子"到"复述句子"，再到"用句子理解后续事件"。

- 可迁移部分：给世界观/阵营各配一句"代言句"。
- 不可照搬部分：具体句子。
- 置信度：高（六组格言跨章承担主题功能）。

### PATTERN-13｜历史与文化符号的再解释（真实史实被重新编码）

- 解决的问题：陌生设定（外星文明、宇宙尺度）缺少读者熟悉的抓手。
- 核心机制：挪用真实历史人物、事件、画作作为设定的"容器"，把陌生内容装进熟悉的符号里，再在设定揭晓时反转其含义。
- 文本中如何运行：1453 年君士坦丁堡陷落被解释为四维碎块事件；周文王/孔子/墨子成为三体文明的文明试错者；牛顿与秦始皇同台组建计算机；凡·高的《星空》与二维太阳系重合。
- 跨章支持：chapters/0037.md#L185-L189；chapters/0004.md#L42-L46；chapters/0012.md#L32-L116；chapters/0018.md#L6-L18；chapters/0041.md#L1064-L1072。
- 反证 / 不成立位置：挪用过度会让读者误读历史本身，书内每次都明确"这是游戏/异世界设定"，与真实历史保持距离。
- 中间因果链：熟悉符号 → 进入陌生设定 → 符号被重新解释 → 读者同时获得熟悉感与新认知。
- 读者经历：先认出符号，再被"原来它另有所指"击中。
- 必要前提：符号挪用要有明确边界，不能篡改真实史实让读者混淆。
- 失败模式：只挪用不反转，符号变成摆设；或反转太牵强，破坏熟悉感。
- 可迁移部分：用读者熟悉的文化符号做陌生设定的第一层包装。
- 不可照搬部分：具体历史事件与人物。
- 置信度：高（四组历史符号承担世界观包装）。
- 能力地图标签：C16 世界质感 / C15 文学功能。
- 最小迁移测试：用读者熟悉的一个历史人物作为异世界向导，写他如何被"重新解释"。

### PATTERN-14｜宇宙尺度中的私人情感（礼物/约定/爱作为变量）

- 解决的问题：宇宙级情节容易让情感线显得渺小或多余。
- 核心机制：把私人情感（礼物、约定、爱）放进宇宙尺度，让"一颗星星""一个宇宙"成为情感载体，同时让"爱"成为影响文明决策的变量。

- 必要前提：情感载体必须具体（星星、约定、留言），不能只有"爱"这个抽象词。
- 失败模式：情感线独立于主线，读者感觉是两条故事。
- 可迁移部分：给宏大主线配一个具体的私人信物或约定。
- 不可照搬部分：星星/宇宙/约定地点。
- 置信度：高（三组情感载体跨章承担主线连接）。
- 能力地图标签：C04 情绪传递 / C03 人物心理。
- 最小迁移测试：让主角在宇宙级任务里带一件私人信物，并让它在关键时刻被使用。

### PATTERN-15｜毁灭的视觉奇观化（末日被写成可看的艺术）

- 解决的问题：毁灭若只写伤亡数字，读者麻木；需要视觉上无法忘怀的画面。
- 核心机制：给末日/灾难配一个极简但独特的视觉模型（风扇、扑克牌、年轮、巨画、雪花），让读者记住画面而非伤亡。
- 文本中如何运行：三日凌空"像一轮巨大的风扇将死亡之风吹向大地"；水滴让两千艘战舰"像一叠被推开的扑克牌"；太阳坠入二维形成"年轮"；二维地球的海洋变成直径五千千米的雪花；凡·高的《星空》与二维太阳系重合。

- 反证 / 不成立位置：奇观若过度美化会稀释悲剧（水滴的美学误导几乎致命），书内以"死亡的画面"与"死亡的事实"并置避免。
- 中间因果链：灾难 → 独特视觉 → 画面定格 → 读者凭画面重述灾难。
- 读者经历：先"哇"，后"原来那是毁灭"。
- 必要前提：视觉模型要来自熟悉经验（风扇、扑克牌、雪花、年轮）。
- 失败模式：画面太抽象，读者记不住；或太血腥，读者回避。
- 可迁移部分：给每个大场面配一个"可描述的比喻模型"。
- 不可照搬部分：具体比喻。
- 置信度：高（四组灾难视觉跨章成立）。
- 能力地图标签：C15 文学功能 / C04 情绪传递。
- 最小迁移测试：用一句话给一场灾难配一个日常物比喻，让三个人复述。

### PATTERN-16｜虫子隐喻与反讽（贬低被反转为抵抗）

- 解决的问题：全书的"人类渺小"主题若只说一遍，容易成为口号。
- 核心机制：用"虫子"作为人类自我定位的隐喻，先接受贬低，再在某个场景把比喻反转成抵抗宣言，让同一意象完成贬低与反抗双重功能。
- 文本中如何运行：三体人说"你们是虫子！"；大史用蝗虫反驳"虫子从来就没有被真正战胜过"；褐蚁与蚂蚁作为非智慧旁观者串起全书。
- 跨章支持：chapters/0034.md#L396-L400；chapters/0035.md#L86-L92；chapters/0036.md#L145-L259；chapters/0036.md#L9721-L9739。
- 反证 / 不成立位置：反转只发生一次，之后"虫子"意象回到非对抗状态（蚂蚁旁观），说明反讽需要特定场景触发，不能全程保持高亢。
- 中间因果链：被贬低 → 接受比喻 → 找到比喻的另一个面向 → 反抗获得新定义。
- 读者经历：从憋屈到被点燃。
- 必要前提：反转要基于同一比喻的客观事实（虫子确实未被灭绝）。
- 失败模式：反转太廉价，读者觉得是嘴硬。
- 可迁移部分：让对手的侮辱性比喻成为主角的自我定义。
- 不可照搬部分：虫子意象本身。
- 置信度：高（三个场景跨章闭环）。
- 能力地图标签：C04 情绪传递 / C01 故事发动机。
- 最小迁移测试：让反派用一个贬义词称呼主角，结尾让主角用同义词自述。

### PATTERN-17｜个人心智作为文明开关（面壁者/执剑人的不可理解特权）

- 解决的问题：个人如何在文明命运中承担分量，且不显得自大。
- 核心机制：设置一种制度化的"个人心智特权"（面壁者不被理解、执剑人不可预测、最终决定权条款），让一个人的内心成为文明开关；再让"责任"把这开关压到个人肩上。
- 文本中如何运行：面壁计划规定面壁者不解释任何行为；执剑人凭威慑度曲线承担两个世界；程心保留"危害生命时唤醒我"的否决权；她的责任阶梯从学习延伸到宇宙命运。
- 跨章支持：chapters/0036.md#L1846-L1860；chapters/0036.md#L2144-L2154；chapters/0038.md#L1029-L1043；chapters/0039.md#L2660-L2690；chapters/0042.md#L1195-L1217。
- 反证 / 不成立位置：特权也意味着无人能验证其正确（罗辑的咒语被当笑话、程心的选择被全人类承担后果），"不可理解"既是权力也是牢笼。
- 中间因果链：制度化特权 → 个人心智成为唯一变量 → 读者只能评估"这个人会怎么想" → 责任与恐惧同时压到人物身上。
- 读者经历：先好奇这个人想干什么，再担心他想错。
- 必要前提：制度要让"不被理解"有可执行的外壳（法律、按钮、条款）。
- 失败模式：人物心智太透明，特权失去意义；或太封闭，读者无法代入。
- 可迁移部分：给主角一项"不需要解释"的权力，让读者在不安中跟随。
- 不可照搬部分：面壁/执剑的具体制度。
- 置信度：高（三套个人开关制度跨章闭环）。
- 能力地图标签：C01 故事发动机 / C03 人物心理。
- 最小迁移测试：给主角一个"按下去就决定他人命运且无需解释"的按钮，写读者是否信任他。
