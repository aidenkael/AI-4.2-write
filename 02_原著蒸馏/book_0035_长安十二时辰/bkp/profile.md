# BookProfile：《长安十二时辰》

## 总体画像

实时危机叙事，以物理倒计时、威胁接力与政治压力三套时钟维持长篇运行；强项集中在信息配给、行动因果、多 POV 群像、知识嵌入动作、道具旅程、人物行为证据与高压中的功能性换气。

## 签名能力

- 阶段危机真实兑现后立即把解决动作转成更具体的新债。
- 同一大谜底分层、换渠道发放，揭示不断改变下一步行动。
- 专业知识不是背景说明，而是人物能做什么、怎样赢、如何犯错的因果部件。
- 人物心智主要由选择、习惯、物件处理和稀缺内心发放累积。
- 多 POV 通过各线独立目标、局部揭晓和阶段汇合维持定位。
- 小人物生活感承担换气，同时仍带信息或行动增量。

## 边界

- ch_0007 与 ch_0023 的多线密度接近定位负荷上限。
- ch_0017–ch_0018 的连续高强度动作可能超过部分读者耐受。
- 部分巧合、时间弹性与终局知识解法高度依赖前置铺垫；拆离长篇账本后不可直接复制。
- 没有启动新 Deep Dive；四个候选只保留为未深挖边界，不冒充已验证专项结论。
