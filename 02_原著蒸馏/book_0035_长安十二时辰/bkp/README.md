# BKP：《长安十二时辰》

> **FINALIZED** — `knowledge/cards.md` 是正常创作检索的 canonical 知识层；`author_view.md` 是作者可读派生投影，不是第二套权威知识源。

本包把冻结的 707 条 Discovery 压缩为少量面向 `story_design / longform_plan / chapter_plan / scene_write / review / revise` 的知识卡。原始 Discovery 留在只读实验审计层；Writer 或未来 Context Compiler 不应直接搜索几百条 Raw Discovery。

- `knowledge/cards.md`：机器检索与后续上下文消费入口。
- `profile.md`：作品能力画像与边界。
- `work_map.md`：阶段地图。
- `author_view.md`：八区快速阅读投影。
- `identity.json`：来源指纹、协议版本、卡数与 provenance。

单书最高默认仅为 Work-specific Pattern；本包不证明普遍 Production Rule，也不得写入原创作品 Canon / Story State。
