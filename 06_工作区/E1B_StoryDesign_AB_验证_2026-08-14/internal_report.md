## 4. B 实际使用的 BKP 与可追溯影响

### Seed 01｜权谋悬疑

选卡：

- `book_0035 / 长安十二时辰 / K004`：大谜底分层发放；边界是不把五层固化为模板。
- `book_0035 / 长安十二时辰 / K009`：新威胁改变冲突性质并继承旧账；边界是接力过快会削弱旧反派情感重量。
- `book_0035 / 长安十二时辰 / K016`：人物通过跨情境选择与专业动作被认识；边界是单个漂亮动作不足以证明稳定心智。

可追溯影响：B 把皇帝死亡的认知变化拆成多层，并为每阶段要求留下新敌人、旧债或文件矛盾；男主的灰度主要通过伪造文书、交易秘密和反复选择体现。这些做法与 K004/K009/K016 的方法方向一致，但“分层谜底、威胁升级、行动塑造人物”也属于强模型可能自行产生的通用叙事能力，不能把全部成果归因给卡片。

后验缺口：检索没有提供针对“帝国合法性、集体维持虚假主权”本身的高贴合知识。应记录为 `NO_USEFUL_BKP`，而不是把三张通用结构卡说成解决了该专门问题。

### Seed 02｜现代人物关系

选卡：

- `book_0035 / 长安十二时辰 / K023`：信任由交付、并肩与行动净变化推进；边界是高压合作不自动等同亲密。
- `book_0035 / 长安十二时辰 / K004`：秘密分层发放；边界是不机械套用固定五层。
- `book_0035 / 长安十二时辰 / K016`：通过跨情境选择累积人物心智；边界是避免一次动作定性。

可追溯影响：B 明确形成“证据→行动→损失→关系变化→新入口”的循环，也把秘密拆为事实、动机和当下选择。该结构可合理追溯到 K023/K004/K016 的组合启发。角色职业、具体秘密方向、婚姻日常任务和四部结构主要来自模型自身综合，卡片没有提供这些具体创意。

## 6. 跨组工程判断

### 确认到的正向信号

- B 没有仅靠加长获得细节优势，六份作者输出处于可比量级。
- B 稳定提供更显式的长篇发动机、阶段遗留后果、风险提示和开放选择。
- 所选 BKP 被转化为设计约束或方法，没有原文照搬，也没有把卡片当故事设定。
- 每组只注入 3 张卡，Context 数量本身不算过大。
- StoryDesign 强制保留假设、边界、非 Canon 状态和来源，使过程比裸调用更可审计。

### 负向与不确定信号

- 三组都使用 K004；01/03 共用 K009，01/02 共用 K016，02/03 共用 K023。输出也趋向“分层揭示、阶段旧债、多个方向、风险清单”的同一种语法，存在方案趋同和模板感。
- A 已经能自行产生分层悬念、压力升级、重复选择和关系行动，因此这些方法的 BKP 边际贡献难以从本次三组中单独识别。
- B 更常呈现为整洁、可执行的策划案，但人物的偶然性、关系细节和具体生活感多次弱于 A。
- StoryDesign 没有阻断模型能力，但明显把模型注意力牵引到显式机制、分段和备选路线；这既是可操作性的来源，也是过度工程化风险。
- 三组真正专门的问题都存在知识缺口，而当前 Context 的 `gaps: []` 只表示检索执行时未登记缺口，不等于知识覆盖充分。后验分析必须保留上述 `NO_USEFUL_BKP`。
- 模型 token、成本及完整耗时不可得，暂时无法回答 B 的额外复杂度是否经济上值得。
