# E1-C｜StoryDesign 稀疏后置 BKP 小验证

状态：`TECHNICAL_EVIDENCE_READY / E1C_PASS_NOT_DECLARED`

本目录是一次性 disposable sandbox。所有人物、地点、情节和设计均为 `proposal_noncanonical`，不形成 Decision、Diff、Canon、Story State authority 或 `approved_plan`。

对照链：

- `b-current/`：Brief → knowledge needs → Retrieval/BKP → Context → 第一轮完整设计。
- `b-lite/`：Brief → 无 BKP 第一轮自由设计 → 薄弱点诊断 → 后置 Retrieval → 0–2 张选卡 → 定点二次设计。
- `comparison/`：独立强模型比较与技术归因。

本实验不修改 StoryDesign runtime，不进入 StoryPlan / Writer。
