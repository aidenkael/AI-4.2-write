# E1-C 独立比较｜第 2 回合解盲技术归因

## 结论先行

解盲映射为：

- **X = B-lite**：先做无 BKP 自由设计，再诊断、后置检索、稀疏选卡并定点修订。
- **Y = B-current**：先形成 Brief 与知识需求，检索、选卡、编译 Context，再一次生成完整设计。

第 1 回合盲评对 X 有清晰但非压倒性的偏好。解盲后，这个结果支持的最强结论不是“后置 BKP 让作品更有生命力”，而是：**B-lite 在检索前的自由初稿就已经拥有绝大多数人物生命感、生活细节、偶然性和自然关系；后置链保存了这些材料，并对两个窄问题做了可见但有限的修订。**

B-current 的优势也真实存在：现实利益类型更宽，宏观结构更容易检查，长篇阶段、中点反转、风险与作者待决项更清楚。它并不是失败版本，只是作者可见文本更像经过分项审查的策划案，立即生长场景的能力弱于 B-lite。

本报告不对两版做数字文学评分，也不对 E1-C 作 PASS / FAIL 判断。

## 一、解盲后的最终文本比较

### B-current 更好的地方

1. **现实利益谱系更宽。** 水泵是安置后谋生本钱，木匾可卖钱还债，分红账可能改变补偿也可能重新分配羞耻；相比 B-lite 较多围绕记忆物件，B-current 更主动地把钱、生计、产权、隐私和声誉放进同一辆车。
2. **宏观长篇骨架更清楚。** “线路完整—城分区—线路缩短—只剩末班”的四部推进、中点“成功带走却伤到他人利益”、后段处分与押金受损，便于作者检查中段是否升级、结尾是否只是水位高潮。
3. **行动自由度说明得更完整。** 乘客可以绕开司机、自行失败或合力迫使她改主意，司机不被设成七条线的唯一裁判。
4. **风险与作者控制边界更易操作。** 七件物品任务化、司机圣人化、执行者恶人化、灾难高潮化四类风险，以及时长、违法边界、母女结局三个待决项，都被明确摆到作者面前。
5. **部分运营约束更集中。** 里程交接、监控、通行权、封控和产权之间的限制，在发动机段落里解释得较整齐。

### B-lite 更好的地方

1. **人物先以生活动作出现。** 梁秋屏认人靠站点与零钱习惯，驾驶台有螺丝刀、塑料袋、黑苦丁茶，首班扫飞蛾、抄未撤站名、断网记一元欠费。这些不是人物功能说明，而是可进入正文的行为质地。
2. **配角具有不完全服务于议题的私人物质感。** 郭兆云闭眼知道齿轮卡点，甘驰修车照价，石月婆真心喜欢新房设施，徐德贵没有宏大理由却天天惦记漏掉的小碑，周行带着复写纸和碘酒味。
3. **关系通过办事后果生长。** 运齿轮、撞踏板、扣款、守口、后续拒运、照价修门、信封缺钱组成一条跨数趟车的关系链；叶青荷留下锯口又牵连同巷复核。这比预先声明谁结盟、谁欠谁更自然。
4. **材料阻力更能直接生戏。** 倒片机拆底座分三次运、主轴箱四十多公斤且铅封入照、轻薄登记簿却不能按普通行李转交、门框只锯窄木条仍会留下复核痕迹。
5. **作者继续写的冲动更强。** B-lite 留下的是“下一趟车会怎样”的局部问题，而不是主要留下一组需要作者继续选择的结构控制项。
6. **作者可见稿的委员会策划案感较弱。** 它仍有七人七物、四变量、四季、两种终局等设计痕迹，但具体事故和人情摩擦不断打破框架的整齐。

### 两版近似之处

- 都守住了现实主义、非灾难大片、非幕后阴谋的 Seed 边界。
- 都让女儿拥有自己的意志，并把母女冲突落在积蓄、报名/复读期限和风险分配上。
- 都让“唯一可靠的运输者”逐步形成；可靠不等于无私、圣人化或有求必应。
- 都用线路收缩、城市机能消失、搬迁期限和承诺后果维持长篇。
- 都允许物件失败、放弃或失去用途，不要求七件全部成功带走。
- 都保留地域、政策、女儿道路、物件结局和最后一班车等作者开放项。
- 中段持续性总体接近：B-current 的宏观防失速能力更强，B-lite 的局部因果续航更强。

## 二、B-lite 从第一轮到最终稿：什么被保留，什么被改变

### 第一轮已有且被保留的有生命力内容

下列盲评中被认为最有优势的材料，在任何 B-lite 检索之前已经存在，不能归因给后置 BKP：

- 梁秋屏十九年驾龄、认人方式、驾驶台物件、扫飞蛾、抄站名、记欠费，以及从等两分钟、捎药、递话逐步成为可靠运输者。
- 车厢里的菜叶、石灰粉、纸箱、瓶装菜籽；倒片机的油腻；周行身上的复写纸与碘酒味；徐德贵鞋边的白灰。
- 郭兆云、谭素珍、甘驰、叶青荷、石月婆、周行、徐德贵的姓名、年龄、职业、基本物件和大部分混杂动机。
- 石月婆喜欢新房电梯和抽水马桶，谭素珍不负责身世谜团，甘驰与梁秋屏不强设爱情，徐德贵没有浪漫化理由。
- 七人散在不同班次而非整齐组队；郭兆云与石月婆互讽，叶青荷向甘驰借锯，周行不躲徐德贵，周行与梁妍只互相羡慕。
- 错拿菜篮、临时检查、亲戚突然上车、普通护坡坍塌改道、空座先于告别等偶然性。
- 线路、物品、人情、存款四项联动；女儿拥有自己的发动机；春夏秋冬随线路物理缩短；两个开放结局；蓄水不替人物结算感情。

换言之，第 1 回合盲评中“人物生命感”“多数生活细节”“关系天然底色”“少模板化”的主体证据，都来自 **B-lite round 1 的无 BKP 模型能力**。

### 第二轮实际改变的内容

第二轮没有改人物名单、核心关系、季节结构或结局方向，而是集中做了两类修改：

1. **把可靠性改写为跨情境可观察的专业选择。** 在“答应了就到、拒绝也不出卖人”之前新增掂重量、看包装、问交给谁；随后用倒片机齿轮—急刹损坏—四百元扣款—守口—拒运主轴箱—甘驰照价修门—梁妍发现信封缺口，替换了初稿较抽象的四变量说明。
2. **把部分物件限制改成动作和后果。** 倒片机要卸铸铁底座、包齿轮、分三次运；登记簿虽轻却不能普通转交；主轴箱有四十多公斤、木箱、铅封和补偿风险；门框改为较窄木条但有清点编号，试锯留下痕迹并引来二次复核。
3. **新增一条失败支线。** 叶青荷停手仍造成同巷冻结物品更难移动，甘驰迁怒；梁秋屏只能替她带卷尺和旧围裙，不能把门框变成合法行李。
4. **删减或收束少量泛化表述。** 初稿中“拆座椅藏东西”等较泛的可能性没有继续扩张，风险段和季节段更紧，以给具体因果接力腾出篇幅。

这些修改确实改善了“发动机已被说明但尚未充分演示”和“物件受限仍停留在规定标签”两个问题；它们没有创造 B-lite 的基本生命力，而是让已有材料更可运行。

## 三、两条链的 BKP 实际改善了什么

### B-current：P18 的可见作用与不可归因部分

B-current 从《三体》候选中选入 P18“选择—代价循环”，并明确缩小到日常人际尺度。最终稿中“每次帮或拒绝都会制造下一轮代价”、藏泵可能被查并耽误报名、拒绝账册后从别处泄露并反过来牵连乘客，都与这张卡的机制相符。它最可能强化的是：**不让外部惩罚者凭空降临，而让行动本身产生后果。**

但不能据此声称 P18 给 B-current 带来了独有提升：

- Seed 本身已要求现实利益持续推动长篇，司机每次帮或拒绝产生后果也是自然故事设计判断。
- B-lite 的无 BKP 初稿已经提出线路、物品、人情、存款联动，以及油费、罚款、垫付侵蚀母女积蓄，说明该能力不依赖 P18。
- P18 的 source scope、boundary、confidence、evidence 均缺失，且原始尺度是文明级后果；B-current 自己也把使用置信度标为低。
- B-current 没有同链无 BKP 对照稿，无法观察“有 P18”相对“无 P18”的差分。

因此，对 B-current 最保守的归因是：P18 **提供了一个被显式记录的因果检查框架**，可能帮助保持选择—后果一致；人物、物件、四步任务、四部结构、现实利益配比、风险清单和开放项主要仍应视为模型根据 Seed/Brief 生成的能力，不能算作 P18 的成果。

### B-lite：K016 的可见作用与不可归因部分

B-lite 后置选入《长安十二时辰》K016，只取“人物的能力、伦理和欲望要通过跨情境的专业动作与后果累积”这一机制。前后稿差分中，新增的掂重量、查包装、承担扣款、守口、下一次仍拒绝重物，确实与 K016 的 application boundary 高度一致。相较 B-current 的 P18，K016 有 scope、boundary、confidence 和 evidence，卡本身质量更完整，且使用尺度更接近人物塑造。

不过，K016 的独立因果贡献仍然有限且无法被隔离：

- B-lite 初稿已写出“可靠不等于无私”、收费、拒绝、判断错和承担工作风险，也已经有专业动作与关系证据。
- W1 诊断在检索前已经准确指出需要“小事改变下一次选择”的跨阶段因果接力；第二次模型调用本身就获得了明确修订目标。
- K016 是很通用的人物塑造原则，强模型无需读到该原著卡也可能做出同样修订。
- 没有“同一诊断、同一第二轮、但不注入 K016”的对照，不能把新增链条中每个细节归功于卡。

所以 K016 实际提供的是一个**有来源、有边界的复核镜头**，帮助第二轮把“可靠”从说明转成至少两个压力情境下的可比较行动；它不是 B-lite 人物生命感的来源。

### 明确不需要 BKP、或本次 BKP 没有改善的部分

- B-lite 的人物、生活细节、偶然性、基本关系与四季推进，均在无 BKP 第一轮形成。
- B-lite 的 W2 没检索到可用卡；倒片机拆运、主轴箱重量与铅封、门框锯口和复核，明确是依靠初稿事实与一般创作判断修出的，不能借名给 BKP。
- B-current 的人物清单、利益分布、分部结构、风险清单与作者待决项，没有证据表明来自 P18。
- “选择导致后果”“用职业动作塑造人物”都属于成熟模型可以自行使用的基础叙事能力；BKP 的合理角色至多是挑战、校验、提醒或提供边界，而不是冒充原创来源。

## 四、副作用与原著结构影子

### 模板化、分层、分卷、多路线与风险清单

B-current 的作者可见稿更明显地呈现策划模板：每件物品四步、每圈两层、四部推进、四项风险、三个作者决定。其优点是易审查、易调度，副作用是人物像被放进一个覆盖全面的矩阵，文本常先说明功能再给例子。多路线没有真正实现为复杂支线，但“七条线错峰交叉＋四部结构”已经带来较强的项目规划感。

不能把这种模板化简单归罪于 P18。P18 只涉及选择—代价，四步、两层、四部和风险清单更可能来自一次性完整设计任务、Brief 的覆盖要求与模型惯常规划方式。也就是说，**B-current 的委员会策划案感是整条前置规划姿态的表现，不是单张卡的可证副作用。**

B-lite 第一轮也自然生成了四变量、四季与两种结局，说明模型在无 BKP 时同样会结构化。后置链的关键正面作用是没有再接受 K001 多时钟、K009 威胁接力或 K020 反派认知算法，也遵守了“不新增分卷、完整章纲、多路线结构”的修订边界。最终稿因此仍有结构痕迹，却没有进一步膨胀。其内部产物——诊断、knowledge needs、八候选审阅、Context、preservation audit、trace——本身非常流程化；这些有审计价值，但如果全部暴露给作者，同样会形成委员会流程负担。作者可见稿能否保持轻量，比内部文件数量更重要。

### 人物与关系自然度

B-lite 的人物与关系自然度主要来自第一轮自由设计；后置修订保留了非对称班次、互相讥讽、借锯、回避座位、互相羡慕等不为统一剧情服务的关系，并用一条具体后果链加深梁秋屏—郭兆云—甘驰—梁妍之间的动态。这里没有发现明显的 BKP 压平人物副作用。

B-current 的人物动机具有真实矛盾，但更多由“身份＋物件＋议题张力”呈现，关系多以债务、旧识、结盟、偏袒等规划语言说明。其自然度较弱不能被证明是前置 BKP 造成的；更可能是一次调用需要同时交付人物、发动机、阶段与风险时，模型优先保证覆盖面的结果。

### 原著结构影子

- **B-current /《三体》P18：** 最终稿保留了“选择自身生出更大后果”的抽象影子，但已缩小到罚款、通行、报名、信用等日常尺度，没有叶文洁—罗辑—程心式人物接力、文明尺度、威慑系统或末日结构。可见的是通用因果框架，不是原著情节模仿；同时这套框架本来就可由 Seed 推出。
- **B-lite /《长安十二时辰》K016：** 最终稿只吸收跨情境专业动作塑造心智。多时钟、威胁接力、反派认知算法均被拒绝，四季线路推进在检索前已存在，因此没有证据显示《长安十二时辰》的限时结构或动作类型进入成稿。

两条链都没有出现明显的原著情节复刻。B-lite 的拒绝审计更有力地证明它主动挡住了不合题材的结构影子；B-current 虽做了尺度限缩，但选择一张缺少来源元数据、尺度悬殊的卡，本身没有提供足够增量。

## 五、卡数与成本是否合理

### 0–2 张是否合理

**作为本次单 Seed 的工作上限，0–2 张合理，而且 0 必须是真实可选结果。**

B-lite 给两个窄知识需求设上限 2，最终只选 1 张，明确把 KN2 标为 `NO_USEFUL_BKP`，没有为凑数强套多时钟、反派或文明级卡，这是合理的稀疏性。B-current 虽允许不超过 3 张，也只选 1 张；但 top-8 全部来自《三体》且大多严重错位，唯一入选 P18 又缺 scope/boundary/confidence/evidence。对这批候选，**选 0 张同样可能比勉强选 P18 更合理**。

因此，证据支持的是“少量、可为零、逐张说明为何用/不用”，不是“每次固定选一到两张”。是否长期把上限定为 2，仍需更多 Seed 检验。

### 额外模型调用、检索与 Context 是否值得

运行记录显示：

- B-current：1 次模型调用，1 次检索，检索耗时 104.236 ms，选 1 张。
- B-lite：2 次模型调用；第一轮无检索，第二轮 1 次后置检索，耗时 83.192 ms，选 1 张并编译后置 Context。
- 两条链的 token、cost 与完整模型耗时均未暴露。

83.192 ms 与 104.236 ms 的差异没有决策意义；检索本身都远低于一次强模型调用可能带来的总耗时。真正的额外成本是 B-lite 的第二次模型调用，以及诊断、选卡、Context、变更审计的流程复杂度，但当前无法量化其 token、费用或模型时延。

就成稿差分看，**B-lite 的第二轮定点修订是值得的，但 BKP 检索与 Context 是否是必要成本，证据不足。** 第二轮确实增加了跨趟因果链和材料阻力，使盲评中特别看重的“发动机已演示运转”更强；若故事设计价值较高，这种窄修订有实际意义。然而：

- B-lite 绝大多数盲评优势在第一次无 BKP 调用后已存在。
- W1 在检索前已被诊断出来；K016 很通用，无法排除同一模型直接修复。
- W2 没有可用 BKP，实际改进仍由模型一般判断完成。
- 两链不是“除检索时机外完全相同”的控制实验，不能用 X 的盲评胜出证明后置检索的投资回报。

因此，本例更能支持“**先保存自由初稿，再做一次窄诊断与修订**”的价值；对“每次窄修都必须检索并编译 Context”只能给出条件性支持：检索便宜、卡高匹配且有边界时可用；若只召回通用常识或错位卡，应允许 0 张并直接修订，而非为了流程完整强行注入。

## 六、证据范围与长期原则建议

本实验只有一个 Seed、同一模型、各一条生成链和一次盲评。两链的提示与调用次数不同；B-lite 也没有“同一第二轮诊断但无 BKP”的消融对照。由此可以证明的只是：

- 在这个 Seed 上，无 BKP 第一轮可以产生高生命感、具体生活与自然关系。
- 在这个 Seed 上，后置流程成功保存了这些材料，并做了少量有用修订。
- 在这个 Seed 上，问题驱动检索比宽泛前置检索召回了元数据更完整、尺度更接近的卡，同时能拒绝不合题材候选。

建议把 **“BKP 后置、稀疏、问题驱动”标为 `LONG_TERM_PRINCIPLE_CANDIDATE`，暂不升级为长期原则。** 候选应附带这些条件：先冻结自由初稿；先以文本证据诊断窄问题；选卡可为 0 且不按排名凑数；Context 只含实际选中卡；逐项记录保存与改变；若卡只是模型常识或与问题错位，允许不注入。

这个建议来自单 Seed 的正向迹象与清晰归因边界，不是稳定普遍规律，也不是 E1-C 阶段结论。
