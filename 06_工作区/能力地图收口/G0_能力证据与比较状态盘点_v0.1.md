## 1. 本轮范围与证据规则

### 1.1 范围

- 逐项盘点 C01–C20 的真实证据状态与实际比较状态。
- 逐一盘点当前重点上游项目（至少 12 个）。
- 建立"上游 × 能力覆盖矩阵"。
- 识别真正能力空白与可能成熟度误标。
- 不搜索新 GitHub 项目；不新建 Benchmark；不修改能力地图 v0.1。

### 1.2 证据规则

**实际比较状态**（每项能力/项目关系只能标一种）：

| 代码 | 含义 | 要求 |
|------|------|------|
| A = 正式实测 | 有冻结输入、正式运行/对照、结果记录，且可追溯 | B02-G Round2A 级别 |
| B = 轻量实测 | 做过真实任务或 Smoke Test，但不是完整正式 Benchmark | B09 Round01/02A 级别 |
| C = 代码/架构审阅 | 读过代码、README、Skill、Prompt、工作流或架构，无真实任务效果比较 | 本地冻结后只读审阅 |
| D = 行为/文档观察 | 根据公开说明、已有报告或运行行为了解，无代码级证据 | 仅根据 README/文档 |
| E = 未实测 | 只有候选关系或问题意识 | 仅列入候选池 |

**禁止**：把"出现在候选池""被讨论过""被 clone 过""被许可审计过""被列入能力地图"写成"已实测"。

### 1.3 成熟度标记（来自 v0.1，本轮不修改）

- M0 未研究 / M1 候选已知 / M2 协议可测 / M3 初步验证 / M4 跨样本验证 / M5 生产固化

### 1.4 许可证状态分类

| 标记 | 含义 |
|------|------|
| P1 | 当前私人研究可直接使用（MIT / Apache-2.0） |
| P2 | 当前私人研究可使用，但未来公开/商业化需复审（CC BY-NC-SA / AGPL） |
| P3 | 许可证/授权未完全核实，仅可研究公开思想/行为 |
| P4 | 当前存在明确禁止或无法使用的限制 |
