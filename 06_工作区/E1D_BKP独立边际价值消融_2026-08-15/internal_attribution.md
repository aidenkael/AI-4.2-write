# E1-D｜解盲后内部归因

状态：`TECHNICAL_EVIDENCE_ONLY / E1_PASS_NOT_DECLARED`

## 结论

本次证据结论为：

`BKP_INDEPENDENT_VALUE_SUPPORTED`

但支持范围很窄：K016 的独立增益主要落在 W1 的“人物心智如何通过跨情境专业动作、资源取舍和后果承担被读者逐步建立”上；它不证明 BKP 普遍有效，不证明 W2 的事实性改善来自 BKP，也不宣布整个 E1 通过。

支持该结论的核心证据是：两位互相独立、看不到 mapping 与 BKP 的盲评者都窄幅选择 Version Y；解盲后 Y=C1。两人又一致指出，Y 的优势不是单纯更完整，而是把梁秋屏的一次越界、拒绝撒谎、承担停开与收入损失、此后拒绝复制冒险，组织成可预测但不绝对一致的职业心智证据。这个差异与 K016 的 statement、conditions、mechanism、boundary 高度对应，并在 C1 的三个可定位动作中出现。

同时，C0 已经靠强模型自身二次思考解决了 W1/W2 的大部分内容。因此本次不是“没有 K016 就修不好”，而是“在相同诊断已经足够有效时，K016 仍给出一个小而可辨认的聚焦增益”。

## 解盲事实

- 随机方法：cryptographic random byte parity；结果为 even。
- sealed mapping 在盲评前完成。
- Version X = `c0_no_bkp`。
- Version Y = `c1_with_bkp`。
- 两份盲评的模型均为 `gpt-5.6-sol / xhigh`，各 1 次调用；`mapping_read=false`、`technical_inputs_read=false`。
- 两位评审都选择 Y，但都把选择描述为窄幅，而不是压倒性胜出。

## 两边共同改善：不得计入 BKP 独立贡献

下列改善在 C0 与 C1 中都出现，因此只能归因于“固定 W1/W2 诊断 + 强模型定点二次修订”，不能计入 K016：

1. W1 从四变量口号落到了跨趟因果。两版都让上一趟的检查、误班、停开、钱或人情改变下一趟人物的请求与信任。
2. W2 的物理阻力明显具体化。两版都补入倒片机的拆分/编号/油污，主轴箱的链葫芦、承重、台阶或车门限制，门框的长度/锯痕/复核，并允许失败、退回或放弃。
3. 两版都保住梁秋屏“收费、拒绝、犯错、承担代价”的非圣人可靠性。
4. 两版都保住原稿的飞蛾、苦丁茶、塑料袋、纸质路单、一元欠费、菜篮、药箱等生活质地，以及梁妍自己的复读犹疑。
5. 两版都没有把七人改成整齐小队、统一阴谋或七件乡愁展品；公交仍只解决运输链的一段。
6. 两版都显著改善了“下一场戏”的可生成性，但 C1 的场景入口更集中、更确定。

## 只有 C0 明显出现或更强的部分

1. **散点群像与原稿保真度更高。** 两份盲评都判 X=C0 在“保留原稿优点”上略胜。C0 保留更多年龄、固定班次、家庭处境、人物互讥及一天中不同刻度。
2. **低强度余波更分散。** “未销掉的车号、占地木座、维修票、迟到的交接日期”形成多条并行残留痕迹，不让所有人都绕同一核心事件运转。
3. **不对称关系更尖。** 梁秋屏拒载后甘驰不再免费修，维修费直接抽走梁妍信封；谭素珍更依赖她递钥匙，却仍拒绝让她私运登记簿。这些关系不是同一种教训。
4. **开放性更多。** 主轴箱仍可雇货车、被追回或因吊装费放弃，为后续作者保留更大决断空间。
5. **C0 也自然生成了 K016 所代表的一部分方法。** 梁秋屏根据车门净宽与轮胎下陷拒绝主轴箱、承担维修与停驶后果；这证明强模型在固定诊断下已能自行写出专业判断与代价累积。

因此，C1 的任何“结构更清楚”都不能自动算 BKP 收益；必须只认 C0 没有、且与 K016 机制吻合的差异。

## 只有 C1 明显出现或更强的部分

1. **跨情境职业边界形成可比较的行为序列。** 梁秋屏“肯载锯、不肯让新鲜锯口横过逃生通道”；曾让拆开的倒片机上车，但临检时“不把编号说成公交零件”；面对小碑又要求“本人随车、坐在旁边，检查时自己说明来处”。这些动作不是同一规则的机械重复，而是在不同压力下比较她肯帮到哪里、何时越界、是否撒谎、谁承担风险。
2. **一次错误真正成为共同前史。** 倒片机失败不只增加检查，而是让梁秋屏停开、收入进入租房信封、梁妍久等并揭出模考谎话、周行以后先问绕路、甘驰放弃照搬运输办法。两位评审都认为这比 C0 的多支流网络更明确地改变了下一次行为。
3. **人物反应更分化。** 郭兆云选择躲避，周行没有资格指责却降低信任，甘驰承认拆成齿轮就不是他要保的机器，梁秋屏承认自己曾越界。这些不是统一获得觉悟。
4. **下一场戏更靠近现场。** Y 的未决动作通常带着人物、场所、障碍和不可回避的选择，而不是并列多个作者备选方向。
5. **在 W1 上更少解释“结构如何工作”。** 虽然 C1 仍有标题和四变量复述，但两位评审都判它略少策划模板感。

## K016 可明确归因的独立增益

可合理归因的只有以下窄项：

- 把“可靠不等于无私”从人物说明转成跨情境的职业动作证据；
- 让一次越界、一次不撒谎、后续要求风险归属回到当事人构成可比较序列；
- 让读者可据这些动作更新对梁秋屏的预测，而非只听设计稿说明她可靠；
- 强化 W1 时同时加深人物心智，而不是只增加因果节点数量。

归因理由：这些增益与 K016 的 `statement`、`conditions`、`mechanism` 和“单一漂亮动作不足，必须跨情境累积”的 boundary 一一对应；C1 的应用记录也在修订前限定了同一方向。两份盲评在不知道 K016 的情况下，独立把这个特征识别为 Y 的主要优势。

不可归因给 K016 的内容：W2 的资产编号、放油、绳扣、链葫芦、滚杠、车门/后轴、影像复核、档案交接等事实性或程序性补强。K016 不提供这些知识，C0 也出现了大部分同类改善；W2 在 C1 中仍是 `NO_USEFUL_BKP`。

## K016 的副作用与机械化风险

未出现足以判定 `BKP_NEGATIVE_OR_OVERGUIDING` 的明显机械化。两位评审反而都认为 C1 略少策划模板感、人物略活、W1 更有效。

但有三项真实副作用/风险：

1. **中心事件过度高效。** 倒片机失败同时承担停开、收入、母女冲突、药品交接、郭兆云躲避、甘驰退让，容易让后续所有人围着一个事件转，削弱原稿散点群像的离心感。
2. **原稿纹理略有损失。** C1 压缩了部分年龄、固定班次、家庭处境与小关系细节；两份盲评都判 C0 更好地保留原稿优点。
3. **“专业动作证据”可能滑向行为清单。** 本稿通过场景动作基本避免了这一点，但末段“面对轻重相反的物件仍先做司机会做的事”仍有总结性解释。若继续加卡或逐项兑现，人物会变成边界判定器。

另有不属于 K016 的共同风险：两版都让十九年经验的梁秋屏在明知职业风险时允许高风险物件上车，需要正文用当时压力、利益和错误判断写实，否则运输路径更可信、人物职业判断反而失真。

## 两份盲评的共识与差异

共识：

- 人物更活：Y 略胜。
- W1：Y 更有效。
- 更自然地产生下一场戏：Y。
- 更少策划模板感：Y 略胜，差距不大。
- 保留原稿优点：X 略胜。
- 只能留一个：两位都选 Y，均强调窄幅选择。
- 最重要差异：X 是高密度、分散的残留痕迹/人情物流网络；Y 是少数已发生、不可撤销的失败选择，形成共同行为前史。

差异主要在措辞和风险权重，不影响方向：评审 01 更强调 X 的关系不对称与人物刻度，评审 02 更强调 Y 可能因倒片机事件太中心而削弱七人的独立生活。二者都要求保留 X 的离心细节，不能把 Y 的窄胜理解为整体替换授权。

## 混杂因素与证据强度

这是严格输入冻结但不是确定性复现的单 Seed、小样本实验：

- C0/C1 是独立新会话，模型与 reasoning 相同，但 sampling/temperature 在当前 Agent runtime 中不可控制；版本差异同时包含 K016 与随机采样噪声。
- 每臂只有 1 次正式修订调用，无法估计同条件方差。
- 两份盲评虽然独立且一致，但使用同一模型家族、同一 reasoning，不能等价为跨模型或人类作者复现。
- 文本是 StoryDesign，不是实际章节；“人物更活”和“下一场戏更自然”仍需正文阶段才能最终验证，但本阶段禁止进入 Writer。
- token、调用成本和模型 latency 均不可获得；C1 仅记录墙钟区间约 129 秒，C0 无可比墙钟记录，因此不能做可靠成本效益比。

这些混杂降低结论的外推强度，但不抹掉本样本内的可追溯证据：输入相同、唯一有意差异是 K016、两位盲评在解盲前一致识别 C1 的同一窄优势。

## 对 StoryDesign 默认策略的建议

保留“BKP 后置、稀疏、问题驱动”，但把默认门槛写得更严格：

> 先自由设计并锁定诊断；先判断强模型自身定点修订是否足够。只有知识卡能提供一个可检验、可追溯、而非一般性建议的额外视角时，才注入 0–1 张；默认允许 0 张。卡片只挑战具体薄弱点，不扩展 W2 事实，不要求显式展示，不得牺牲原稿离心细节。

对 K016 这类“行为证据累积人物心智”卡，适用条件应限定为：初稿的人物判断主要停留在解释层，且需要跨情境比较专业边界、资源取舍或后果承担。若强模型已经自然形成同样序列，或卡片只能提示“多写动作”，则边际价值不足，应拒绝注入。

因此本轮支持继续保留后置稀疏机制，但不支持把 BKP 设为 StoryDesign 每次二次修订的默认必经步骤，也不支持增加第二、第三张卡。
