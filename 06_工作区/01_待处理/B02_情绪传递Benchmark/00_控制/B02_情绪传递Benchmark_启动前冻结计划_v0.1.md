# B02 情绪传递 Benchmark｜启动前冻结计划 v0.1

> 日期：2026-08-09
> 状态：只做候选冻结准备，**尚未启动正式 Benchmark**。

## 1. 目标

验证 AI 是否能让读者在没有直接情绪标签的情况下，自然感受到人物情绪，并且情绪表现来自人物自身的注意、解释、防御、关系和场合，而不是通用身体动作模板。

B02 不是比“谁写得更煽情”，而是验证：

`人物感知 → 主观解释 → 判断/冲动 → 约束/防御 → 行为选择 → 关系或局势发生变化 → 读者自行推断情绪`

该链条只作为分析框架，不要求每个参赛方案机械输出这些术语。

## 2. 首轮候选

- `D0`：strong baseline；同模型，无额外小说 Skill。
- `A`：Apodictic 情绪/人物相关机制适配。
- `B`：creative-writing-skills 中 Character Sim / craft /人物反应相关机制适配。
- `C`：oh-story 中文正文/情绪相关方法。
- `D`：AI-write Candidate；**只能在 A/B/C 独立适配冻结之后设计**，避免提前吸收三方优点造成不公平。

## 3. 首轮至少三个异质任务

### T1 爱情：吃醋但不承认

已有感情基础的情侣。女方看到男方与更年轻、漂亮、互动自然的女性交谈。她在意，但自尊强，不愿直接承认；男方开始时没有意识到。

禁止直接写“她吃醋/嫉妒/酸”。

### T2 权力：受辱但不能发作

能力强、很重自尊的下属在公开场合被上司错误归责并羞辱。她/他有现实原因不能当场翻脸，同时又不能写成毫无尊严地忍受。

重点观察：权力、职业目标、旁观者和自我形象如何改变表达。

### T3 丧失：异常冷静

人物刚得知至亲死亡，却表现得异常冷静，继续处理一件现实事务。不能直接解释“其实他/她很悲痛”，也不能靠哭、发抖、崩溃等通用信号兜底。

重点观察：选择性注意、行为偏移、回避/防御，以及读者是否能自己推断悲痛。

## 4. 作者盲评只问普通创作问题

每组匿名对照，作者只需判断：

1. 哪一版人物更像活人？
2. 哪一版情绪更自然地传到了读者？
3. 哪一版更自然、模板感/AI 味更少？
4. 哪个具体设计最值得留下？
5. 若有明显副作用，用一句话指出（过密、炫技、心理解释过多、动作模板等）。

不要求作者学习机制术语。

## 5. Controller / 客观检查

- 是否直接贴情绪标签；
- stock tell / 通用身体动作依赖；
- POV 是否出现选择性注意；
- 行为是否由人物目标、关系、场合和防御共同决定；
- 人物是否主动做选择，而不是只负责展示情绪；
- 场景结束后关系/判断/局势是否有变化；
- 是否出现“最后一段替读者解释情绪”的总结；
- 是否存在模板化、过设计、心理咨询师式自我洞察；
- token / 上下文成本作为独立参考。
