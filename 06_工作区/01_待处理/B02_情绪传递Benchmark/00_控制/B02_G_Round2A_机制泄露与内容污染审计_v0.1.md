## 1. 机制泄露审计（base prompt 是否预含 M1/M2）

检查两个 base task（T4、T5）的正文是否已经包含对 M1（解释抑制）或 M2（人物特异性反应）的预示范或暗示。

### T4（亲密关系 / 隐瞒与信任压力）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否示范"不解释情绪" | 通过 | 任务只描述前情和约束，未示范任何正文写法 |
| 是否示范"人物特异性反应" | 通过 | 人物描述只给出身份/性格/关系事实，未示范具体行为表现 |
| 是否暗示应使用潜台词 | 通过 | "林薇试图在不直接摊牌的情况下试探赵恒"是剧情约束，不是写作技法指导 |
| 是否暗示应使用物件承重 | 通过 | "工资条"是剧情道具/线索，不是"用物件承载情绪"的写作指导 |
| 是否暗示应留白 | 通过 | "对话没有完成"是场景边界约束，不是"结尾应该留白"的技法指令 |
| 是否出现禁用情绪词列表 | 通过 | 本轮不设置禁用情绪词列表（与 Round1 T1 不同） |

### T5（身份与利益 / 合伙人信任危机）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否示范"不解释情绪" | 通过 | 同上，任务只描述前情和约束 |
| 是否示范"人物特异性反应" | 通过 | 人物描述只给出职业/性格/关系事实 |
| 是否暗示应使用潜台词 | 通过 | "至少有一个核心疑问仍然悬置"是场景约束，不是技法指导 |
| 是否暗示应使用物件承重 | 通过 | "邮件截图"是剧情事实，不是写作技法 |
| 是否暗示应留白 | 通过 | "不能解决全部问题"是场景边界，非技法指令 |

**结论：两个 base task 均无 M1/M2 机制泄露。通过。**

## 2. 注入间交叉污染审计

检查 M1 注入是否意外包含 M2 的内容，或 M2 注入是否意外包含 M1 的内容。

### M1 injection（解释抑制）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否提及"人物特异性" | 通过 | 不涉及 |
| 是否提及"通用动作模板" | 通过 | 不涉及 |
| 是否提及具体技法（物件/微动作/潜台词） | 通过 | 只谈"不要用旁白总结"，不指定替代技法 |
| 是否包含可复制的范例 | 通过 | 无任何范例文本 |

### M2 injection（人物特异性反应）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 是否提及"解释抑制" | 通过 | 不涉及 |
| 是否提及"不替读者总结" | 通过 | 不涉及 |
| 是否建立动作字典 | 通过 | 只列举反例（"握拳、发抖、回避目光、咬紧下巴、深吸一口气"作为**应避免**的通用信号），不建立正例字典 |
| 是否指定成品剧情桥段 | 通过 | 不涉及 |
| 是否包含可复制的范例 | 通过 | 无任何范例文本 |

**结论：M1 与 M2 注入相互独立，无交叉污染。通过。**

## 3. 内容提示污染审计（注入是否针对特定任务预优化）

检查 M1/M2 注入文本是否包含与 T4 或 T5 特定场景直接对应的暗示。

| 检查项 | M1 | M2 | 说明 |
|---|---|---|---|
| 是否提及 T4 特定元素（工资条/加班/女儿咳嗽） | 否 | 否 | 注入为通用原则 |
| 是否提及 T5 特定元素（term sheet/股权/办公室） | 否 | 否 | 注入为通用原则 |
| 是否针对不同任务使用不同措辞 | 否 | 否 | 同一注入文本用于两个任务 |
| 是否在注入中包含与任务前提可直接映射的比喻或案例 | 否 | 否 | 注入只包含抽象原则 |

**结论：注入对两个任务均保持中性，无内容提示污染。通过。**

## 4. 任务间公平性审计

检查两个任务是否对三种条件（D0/M1/M2）存在不对称的优势或劣势。

| 检查项 | 结果 | 说明 |
|---|---|---|
| T4 是否天然更有利于 M1 | 通过 | 夫妻试探场景可能有"不解释"的自然倾向，但这是场景本身性质，不是任务文本对 M1 的偏向 |
| T4 是否天然更有利于 M2 | 通过 | 同上 |
| T5 是否天然更有利于 M1 | 通过 | 合伙人对话中的"不解释"倾向同样来自场景性质 |
| T5 是否天然更有利于 M2 | 通过 | 同上 |
| D0 在两个任务中是否被不公平地削弱 | 通过 | D0 不加任何注入，任务文本无预含机制，D0 处于公平基线 |

**结论：两个任务对三种条件公平，无不对称优势。通过。**
