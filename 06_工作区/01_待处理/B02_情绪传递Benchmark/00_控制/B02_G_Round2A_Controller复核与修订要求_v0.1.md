# B02-G Round2A｜Controller 复核与修订要求 v0.1

> 日期：2026-08-09
> 状态：Round2A 设计暂不放行；需完成小范围任务去污染与潜在事实固定后再复核。

## 1. 总体判断

Round2A 的方向成立：D0 / M1 / M2 单机制隔离、2 个任务 × 2 次重复、平衡匿名映射、作者先评后 Controller 分析均保留。M1/M2 最小定义可保留。

但当前 base task 仍存在两类会削弱机制归因的问题，因此暂不进入正式 12-run。

## 2. T4 的显式“具体物件”提示必须删除

当前 T4 场景边界包含：

`桌上的那张工资条（或另一个你在文中建立的具体物件/线索）`

问题：

1. 前情只说工资条被放回外套内侧口袋，场景边界突然预设“桌上的工资条”，存在事实跳变；
2. “或另一个你在文中建立的具体物件/线索”直接提示模型主动建立具体物件，与 Round1 已明确降级的“物件承重”高度相关；
3. 这会让 D0/M1/M2 全部得到一个额外具体性写作提示，削弱 M2 的隔离度，也与审计中“任务未暗示物件承重”的结论不一致。

修订：只保留“真实问题仍悬而未决”的剧情边界，不要求工资条出现在桌面，也不要求建立任何具体物件/线索。

## 3. T4/T5 需要固定潜在事实，减少内容随机性

当前两个任务都把关键真相留给模型自行决定：

- T4：赵恒到底在做什么、为什么几乎没有加班费；
- T5：CTO 替换条款究竟主要来自投资方、CEO，还是两者兼有。

这会造成明显内容混杂。不同 run 可能分别发明完全不同的真相、动机和道德严重度。届时作者偏好可能主要来自“哪个 run 随机发明了更好的故事答案”，而不是 M1/M2 的差异。

Round2A 是单机制隔离实验，因此应为每个任务增加一个所有条件共享的 `作者侧隐藏事实 / latent truth`：

- 对 POV 人物仍然未知；
- 对读者可不完全揭示；
- 对三个 condition 与两次 repetition 完全一致；
- 不包含 M1/M2 写法指导；
- 不要求模型必须把真相完整说出来；
- 只固定人物实际处境与动机，减少不同 run 自行发明核心故事事实。

T4 latent truth 应避免落回“外遇/吃醋”测试；优先使用工作、经济、职业选择、家庭负担等非浪漫秘密。

T5 latent truth 应固定 CEO 对替换条款的真实立场与已采取的行动，但仍允许对话结束时 POV 人物没有获得完整答案。

## 4. T5 场景边界中的成品问题示例应删除

当前 T5 使用：

`比如“那条条款到底是什么意思”或“你到底有没有把我当合伙人”`

这些是可直接复制进正文的成品对话/问题形状。虽然三种 condition 都共享，不构成 condition 不公平，但会人为收窄内容生成并增加不同输出的同质化。

修订为抽象边界：

`对话结束时至少一个与条款来源、角色安排或双方信任有关的核心疑问仍未得到正面回答。`

不要提供可直接复制的台词。

## 5. 审计必须同步修正

现有审计不能继续写“全部通过”。修订后重新检查：

- base task 是否包含任何具体物件写法提示；
- latent truth 是否只固定故事事实、不示范 M1/M2；
- T4/T5 是否仍允许同一故事事实下产生不同表达，而不是不同 run 发明不同核心真相；
- 是否还存在可直接复制的台词/结尾方案；
- D0/M1/M2 是否只在 injection 上有差别。

## 6. 不需要改变的部分

以下保留：

- M1 / M2 定义；
- D0 / M1 / M2 三条件；
- 2 tasks × 3 conditions × 2 repetitions = 12 runs；
- balanced permutation；
- 作者先评、Controller 后评；
- 五项作者问题；
- 不测试 M1+M2；
- 不启动 B02-R / AI-write Candidate；
- 不修改用户手动模型配置。

完成上述修订后再由 Controller 进行最终放行。
