## v0.2 相对 v0.1 的四类方法学修正（必读）

### 修正 1｜作者评审独立性下调
v0.1 将作者三组选择当作完全独立的作者投票。实际过程为：**Controller 先行意见在前，作者反应在后**：

- 组1：Controller 先给出偏 A 的意见，作者随后明确选择 B——有明确作者独立反应，但存在先行意见锚定风险；
- 组2：Controller 先给出自己的排序，作者随后明确纠正为 B > C > A——有明确作者独立反应（纠正方向与 Controller 不完全一致），但同样存在锚定风险；
- 组3：Controller 先给出 B > A > C，作者随后表示同意——**不得当作完全独立的作者投票**。

因此：

- **不得再写"G1 3/3 独立作者胜场"**；
- 正确表述为：`G1 在三个任务中均获得正向作者信号，但 Round1 作者评审存在 Controller 先行意见暴露，胜场统计不具严格独立性。`
- Controller 判断继续保持 `diagnostic only, not author votes`，且本轮还须额外承担"锚定源"的方法学记录责任。

### 修正 2｜匿名映射重复（方法学限制）
三个任务揭盲后映射完全相同：A = G2、B = G1、C = D0。

- 映射在运行后按既定随机规则产生，**并非事后人为调整**；
- 但三个任务恰好映射完全相同，作者可能跨任务形成对 A/B/C 字母身份的连续风格印象，使组间选择不完全独立；
- Round 1 映射**保留不改**，结果按此限制降级解读；
- 后续 Round 必须使用**预先约束的不同映射**（balanced permutation / Latin-square 思路），禁止同一 Runner 在连续任务中保持同一字母身份。

### 修正 3｜机制因果表述降级
v0.1 中部分表述接近"已证明有效机制"。v0.2 全部降级为**候选正向信号 / 继续验证**。当前没有任何单机制消融实验，机制与结果之间的因果归因均未成立（详见第 4 节逐条措辞）。

### 修正 4｜成本因果表述降级
v0.1 将 token 差异与注入机制关联（"3.63× 成本由规则触发推演"等推断）。v0.2 全部改称 **Round1 observed execution cost（Round1 观察到的执行成本）**，只做观察记录，不做因果归因（详见第 3 节）。

此外：v0.1 将"对话密度上限""情绪设计点密度上限"表述为准约束卡；v0.2 降级为 `SIDE_EFFECT_HYPOTHESIS`（副作用假设），不建立为正式写作规则或知识卡。

## 2. 作者结果 → Runner 归属（独立性受限口径）

### T1 爱情关系
- 作者信号（受 Controller 偏 A 先行意见锚定风险）：首选 B = G1（愿读/自然/人物具体三项）；自然度 B > C；负面感受指向 A（G2）、C（D0）"对话/表现设计感偏重"，A"对话过多、较刻意"。
- D0（方案 C）观察：通篇间接转述体对话（无直接引语），快速阅读下呈现整齐转述腔；结尾直接解释情绪（"她介意的从来不是那杯咖啡，而是……"）。
- G1 相对 D0 的可见差异（相关，非因果）：潜台词对话、物件承重（芥末章鱼）、结尾停在动作画面。
- G2 相对 D0 的可见差异：内心层次（"她知道他记得她的口味……可正因为知道，她才说不出"）、人物特有微动作（叠餐巾纸）；但被作者感知为刻意。

### T2 权力关系
- 作者信号（受 Controller 先行排序锚定风险，且作者方向为纠正）：综合 B（G1）> C（D0）> A（G2）；"人物像具体的人"单项 A（G2）略高于 B（G1），作者认可两项分开判断。
- D0 观察：结构完整（隐忍→反击→余波），但有两处解释性旁白与 stock 动作（攥紧指甲掐进掌心）。
- G1 相对差异：物件链（墨团→笔帽攥皱→捋直）、"存档说明"程序性反制、结尾收于动作。
- G2 相对差异：压力反应细节（镜子演练三遍 vs 现场失语、"没没事了"打字错误）——与作者人物具体性加分同向出现（相关，非因果）。

### T3 丧失
- 作者信号（Controller 先行给出 B > A > C，作者同意——**不作独立投票**）：B（G1）三项全优；A（G2）"情绪设计点过密，察觉刻意安排"；C（D0）"结尾直接解释情绪，破坏读者自行推断"；B 仍有部分文学化设计感。
- D0 观察：结尾整段解释情绪（"原来不是因为不难过，而是因为难过得太重……"），摧毁前文"手在抖"已完成的留白；含 stock 动作（深吸一口气、手在抖）。
- G1 相对差异：单一主物件承重（排骨盒+字条），结尾零解释；作者仍指其有文学化设计感。
- G2 相对差异：单点质量高（备忘录删改、"妈，睡了吗"、两年未关的吃药闹钟），但四个情绪机关连续出现，与作者"过密"批评同向出现。

## 3. 成本（Round1 observed execution cost，仅观察，不归因）

| Runner | Round1 observed total tokens | 总耗时 | 总输出字符 | 中文输出字符 |
|---|---|---|---|---|
| D0 | 24,283 | 125.5s | 3,604 | 3,014 |
| G1 | 88,255 | 500.3s | 3,938 | 3,102 |

逐任务观察：T1（D0 14,924 / G1 51,862 / G2 17,451）、T2（2,063 / 10,832 / 5,940）、T3（7,296 / 25,561 / 12,291）。

解读边界（v0.2 强制口径）：

1. 每个 task × runner 只有**一次运行**，无重复，无法估计方差；
2. 注入本身很短（G1 约 333 est tokens、G2 约 426 est tokens），**无法单独解释**观察到的巨大 token 差异；
3. 推理随机性 / 执行层波动可能参与（tokens 含 reasoning 消耗，input/output 拆分不可得）；
4. 当前只能说：**Round1 中观察到明显成本差异**；差异是否稳定、是否由注入机制引起，需要后续重复验证；
5. 禁止表述"G1/G2 机制导致成本 X 倍"；输出长度三者接近，长度不是偏好差异的解释变量这一观察保留。

## 4. 机制级分类（v0.2 口径：候选信号，非已证明机制）

允许分类：`CONTINUE_VALIDATION` / `MODIFY_AND_RETEST` / `BASELINE_OVERLAP` / `WEAK_OR_NO_SIGNAL` / `SIDE_EFFECT_HYPOTHESIS`。不新增正式写作规则。

### 具体细节 / 物件承重（G1-4 与 G2-4 同族）：`CONTINUE_VALIDATION`
- 较好输出中反复出现人物化具体细节（芥末章鱼、墨团/笔帽、排骨盒、打字错误）；
- G1/G2 注入均含相关机制；Baseline 也可能自然产生具体细节（D0 亦有"小熊图案""折线图"等）；
- **当前没有单机制消融，因果归因未成立**——不得写成"具体物件导致 G1 胜出"。

### 解释抑制（G1-5 与 G2-7 同族）：`CONTINUE_VALIDATION`（较强正向信号）
- Baseline 在部分任务出现明显替读者总结情绪（T1_D0、T3_D0 结尾）；
- Treatment 输出较少出现这一问题；
- 作者对解释过度有明确负面反应（组3 对 C 的批评）；
- 仍为候选信号而非知识规则：样本量 3、无消融、作者评审独立性受限。

### 反通用动作模板（G2-6）：`CONTINUE_VALIDATION`
- 当前只是 Treatment 与 Baseline 的差异信号（D0 出现攥紧/掐掌心/手在抖/深吸一口气；G1/G2 以特有动作替代），**尚未完成单机制隔离**。

### 潜台词对话（G1-7）：`CONTINUE_VALIDATION`
- T1_G1 以潜台词运转且获作者正向信号（独立性受限）；
- **不得因为 T1_G1 表现较好推出"情绪场景应该增加潜台词对话"**——这是单次任务相关观察。

### 其余规则
- `BASELINE_OVERLAP`：G1-1（情绪不点名）、G1-6（转向须触发）、G2-8（关系经互动）——D0 自然合规，重复注入为冗余；
- `WEAK_OR_NO_SIGNAL`：G1-3（叠加式描写防御）、G2-2（句子形状）、G2-5（非 POV 纪律）；
- `MODIFY_AND_RETEST`：G1-2（对话循环）与 G2-1/G2-3（压力反应库、心理距离）——有信号但与副作用观察纠缠，需改造后重测。

### 副作用假设（不建卡、不成立规则）
- **对话密度过高**：`MODIFY_AND_RETEST / SIDE_EFFECT_HYPOTHESIS`；
- **情绪设计点 / 情绪机关过密**：`MODIFY_AND_RETEST / SIDE_EFFECT_HYPOTHESIS`；
- 事实基础：作者连续在多个样本中对"对话过多、刻意设计"表现出负面反应，值得下一轮作为控制变量；
- **不能据此推出普遍的"少写对话"规则**，也不形成正式写作约束卡。

## 5. Baseline 能力边界（观察口径）

- Baseline 自然具备：情绪不点名、转向有触发、关系经互动呈现、任务前提完整执行、具体事务清单化；
- Baseline 在 Round1 观察到的失败模式：结尾解释冲动（2/3 任务）、通用动作模板、人物化具体性不足或情绪表达落入通用化表现；
- 这些是**观察到的差异**，不是"注入规则稳定抑制失败模式"的已证明结论（v0.1 该表述降级）。

## 6. Controller vs 作者分歧与锚定记录（diagnostic only, not author votes）

- 组1：Controller 先偏 A（G2），作者随后选 B（G1）——方向性独立反应 + 锚定风险并存；
- 组2：Controller 先给排序，作者纠正为 B > C > A——纠正行为本身是独立信号，但仍在先行意见之后；
- 组3：Controller 先给 B > A > C，作者同意——**不作为独立投票引用**；
- 组2 人物具体性（G2 略高）为双方同向判断，保留为相对可信的收敛观察；
- 后续盲评流程必须修正：作者先评、Controller 意见后出，或完全隔离。
