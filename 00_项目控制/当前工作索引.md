## 当前战略

- 项目目标是尽快形成真实可用的 AI 长篇创作闭环。G0 地图收口与 G1 最小 BookDistill
  均已确认退出，当前进入 G2：以 1–2 部不同类型真实作品验证 BookDistill 的跨书价值。
- 能力地图 C01–C20 与 GitHub 候选池是**持续能力路由**，不是 G0 一次性产物；
  后续 G2 / G3 / 长期生产阶段继续使用：真实蒸馏/创作暴露问题 → 能力地图定位 →
  从已有候选中选相关机制 → 最小真实测试 → 吸收/保留/放弃。
- GitHub 项目按能力取用，不选"总冠军"；许可证符合当前私人研究边界的高价值候选继续保留。
- 普通能力以后默认采用"快速筛选 → 最小真实任务测试 → 作者快速判断 → 吸收/保留/放弃"。
- 严格 Benchmark 只用于高价值、证据矛盾、错误固化代价高的核心机制。
- 每次 Agent 任务只推进当前门禁中的一个明确子目标，不"顺手"跨阶段扩展。
