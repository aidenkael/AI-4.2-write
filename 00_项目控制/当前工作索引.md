## G4 唯一核心目标

证明 AI-write 可以在**不依赖聊天记忆、不把整个项目/全部 BKP 塞给模型、不自动替作者做重大创作决定**的前提下，把：

```text
作者意图
+ 当前作品状态 / Canon
+ 当前创作焦点
+ 希望读者经历什么
+ 少量相关 BKP 知识
```

编译成小而相关、可追溯的创作上下文，并进一步：

```text
1～3 个真正有差异的创作方向
→ 说明依据 / 风险 / 冲突 / 边界
→ 作者选择 / 修改 / 全部拒绝
→ 只在作者确认后更新计划 / Story State
```

G4 不负责证明正文质量；Writer、Reader/Critic/Editor 完整生产闭环留给后续 Gate。

## G4 五种概念工件

1. **Author Intent**：作品方向、作者当前最在意/不想要的东西、Current Focus；
2. **Story State / Canon**：原创作品权威事实与当前状态；
3. **Creation Brief**：当前创作问题、人物欲望/阻力、读者目标、硬约束与自由空间；
4. **Context Package**：从权威状态 + KnowledgeRetrieve 少量 BKP Hit 派生的小上下文；
5. **Decision Record / State Diff**：作者确认后的决策理由和状态变化。

**BKP 参考知识与原创 Canon 必须严格分离。**
