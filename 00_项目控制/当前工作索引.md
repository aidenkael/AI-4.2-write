因此当前判断：**BookDistill v0.1.1 是 vNext 的证据地基，不是可直接批量运行的最终蒸馏器。**

## 当前战略判断

1. 一本书的最终目标是固定 Book Knowledge Package（BKP），而非只有 `model.md + mechanisms.md`。
2. 日常正式写作主要检索已有 BKP，不临时重新蒸馏整本参考书；只有系统新增重要能力维度时才允许升级式再蒸馏。
3. 所有书先做全维度基础蒸馏，再形成 BookProfile；BookProfile 只负责分配专项蒸馏预算，不得提前裁掉未知维度。
4. 蒸馏次数不固定：通常 `1 次基础 + 1～N 次专项`，全能型高价值作品可以深挖多次。
5. 知识等级严格区分：`Evidence → Observation → Pattern Hypothesis → Cross-book Pattern → Creation-tested Heuristic → Production Rule`。
6. 单本作品 Pattern 不得直接升级为 AI-write 写作定律。
7. 开发默认 Borrow-first：先审查成熟开源能力，真正缺口才自研。
8. AI-write 主要自主设计协议、路由、胶水、BKP、BookProfile 路由逻辑、中文长篇适配、作者控制；不从零重造成熟 Writer/Canon/RAG/Continuity 等底层能力。
9. 后台“里子”与作者界面“面子”解耦；当前不开发完整独立写作软件。
