# AI-write 项目推进记忆

> 保存跨会话必须记住的项目方向、重大决策和当前阶段。过程日志不放这里。

## 1. 最终目标

AI-write 是作者主导、AI 辅助的中文长篇小说工作台。

作者主要做：`看正文 → 说感觉/要求 → 接受/拒绝/继续修改 → 做重大创作取舍`。

系统主要做：`知识召回 → Context 编译 → 写作/诊断/修改 → 连续性 → 状态回写`。

后台复杂度应尽量对作者隐藏。

## 2. 长期原则

- Borrow-first；
- 案例只暴露问题，不决定架构；
- 真实任务优先；
- BKP 与原创 Canon 严格分离；
- **作者控制 ≠ 作者审批**；
- **作者反馈是信号，不是默认正确的诊断**；
- 作者不维护后台字段或手动挑 Skill；
- AI 诊断也可能错，冲突要保留证据和不确定性；
- 正式创作阶段性冻结核心工作流；
- 长期文档只留稳定原则。
