**G3｜跨书知识库与创作任务检索：已完成并由作者确认退出。**

最终状态：`G3_RETRIEVAL_VALIDATED / CLOSED`

## 3. G3 收口前唯一需要补的系统性缺口：原著 Discovery

完整能力审查确认：AI-write 的 BKP / Evidence / Boundary 等知识纪律较稳，但“看见原著真正重要的东西”的观察执行方式仍偏单一。

因此在 G3 关闭前，`BookDistill/SKILL.md` 已完成原则级修正：

```text
原著
├─ 默认镜头 A：长篇运行 / 读者动力
│  └─ 借 oh-story + AI-Novel 的成熟方法
├─ 默认镜头 B：Reader / Page Craft
│  └─ 借 creative-writing-skills 的成熟方法
├─ 必要时 Developmental Deep Dive
│  └─ 借 Apodictic 的成熟诊断框架
└─ BookDistill 总编辑
   └─ 回源核证 → 去重 → 组合效果 → 边界/反例/置信度 → BKP
```

关键约束：

- 多个观察镜头必须能够直接阅读原著，不能只吃上一层摘要；
- BookProfile 是导航和预算工具，不是过滤器；
- 允许一条高价值 Observation 由不相邻句子、场景、章节共同支撑；
- 允许保存“重要但暂时难以命名”的 Observation / Inference；
- Discovery 可以宽，最终 BKP 必须克制；
- 不新增固定大 taxonomy，不围绕单个案例打补丁；
- 不修改 BKP v0.1 基本认识论边界：单书最高默认仍是 Work-specific Pattern。

本次修正只改方法说明；**没有改代码、没有改 BKP schema、没有重跑《一九八四》或《三体》、没有启动第三本书。**

## 4. G3 明确没有证明的事情

关闭 G3 不得被误读为以下结论：

1. **没有证明 BKP 已经捕获作品全部创作精华。** 多视角 Discovery 是后续正式蒸馏的正确方法方向，仍需在真实使用中验证效果。
2. **没有证明多书智慧已经可以自动综合成最佳原创决策。** G3 证明的是 Retrieval，不是 Synthesis。
3. **没有证明 Writer 已经因为 BKP 知识而写出更好的原创小说。** 原创质量必须在创作沙盒中验证。
4. **没有证明当前关键词/bigram 检索就是最终检索方案。** 只有真实任务出现明确召回瓶颈时才升级。
5. **没有产生新的 Production Rule。** 单书 Observation / Pattern 仍不能直接升级成普遍写作定律。

## 5. 下一阶段已经确认的两个系统性缺口

这两项不是 G3 尾巴，而是下一阶段正式任务：

### A. Cross-book synthesis｜跨书智慧的情境化综合

未来由 `Context Compiler / Muse / Planner` 负责，把：

`作者意图 + 当前 Canon/人物/关系/章节状态 + 希望读者经历什么 + 少量跨书 BKP Hit`

综合成 1–3 个适合当前原创作品的可选方向，同时保留冲突、条件和边界。

禁止变成“多数书都这么写，所以这是规则”。

### B. Author decision loop｜作者决策反馈环

目标不是让 AI 自动替作者决定一切，而是：

`AI 提供方案 / 证据 / 风险 / 推演 → 作者做重大创作取舍 → 系统按确认结果更新计划/Canon/状态。`

优先借鉴 creative-writing-skills 的 Muse/专业角色分工、Apodictic 的诊断 Firewall、InkOS 的 author_intent/分支比较/确认后写回，以及 AI-Novel 的成熟工程链。

## 6. 下一阶段建议入口

**不自动建立新 Gate。**

G3 关闭后，下一正式方向对应长期路线 `Phase E｜创作核心后台`。启动前由作者确认新的 Gate 名称与最小退出条件。

建议下一次只做 Phase E 的“Borrow-first 组合设计”，不立即开发大系统：

1. Story / Project Bible 与 Canon；
2. Context Compiler；
3. Planner / Outliner；
4. Writer；
5. Reader Sim / Critic / Editor；
6. Continuity；
7. Controller / Author Decision Loop；
8. 跨书 Synthesis 的最小接口。

原则：成熟上游能直接借就借；只为真实剩余缺口写胶水。
