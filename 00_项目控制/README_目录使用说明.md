# AI-Wirte 资料库目录说明

## 基本流程

1. 下载的原始文件放入 `01_原始训练材料`
2. 准备处理的文件复制到 `02_提取工作区\01_待提取`
3. AI 或脚本提取后进入 `03_待人工复核`
4. 人工确认后进入 `04_已复核待入库`
5. 按内容分别存入：
   - `03_长期资料库`
   - `04_写作技法库`
   - `05_优质样本库`
   - `06_作者自有与微调数据`
6. 涉及现代制度向古代转换的内容，同时存入 `07_古今制度转换库`

## 重要原则

- 原始资料不得直接覆盖或修改
- 小说全文不等于有效训练数据
- 参考作品主要提取结构、技法、场景和失败经验
- 后期模型微调以作者确认后的自有内容为主
- 未核实的事实必须标记为待核验
