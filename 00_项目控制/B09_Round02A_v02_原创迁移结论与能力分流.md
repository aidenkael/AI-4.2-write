# B09 Round 02A v0.2｜原创迁移结论与能力分流

> 日期：2026-08-09
> 结论类型：Controller 分析
> 边界：本轮为 4 项能力各 1 个原创任务的 Smoke Test；作者偏好具有方向性证据价值，但不能视为稳定统计结论。

## 一、总体结论

Round 02A v0.2 的 4 组作者匿名评审中，作者对“更愿意继续写”和“更自然”的选择均落在 Treatment。

这说明四项候选能力在对应任务上都产生了作者可感知的增益；同时 Control 在四组中都已自然具备部分、甚至大部分同类能力，因此结论不是“必须新增四个大 Skill”，而是：

- 保留真正有增量的操作原则；
- 避免把模型本来就会的能力重复包装；
- 将能力分流到更合适的专项 Benchmark / 工作台位置；
- B09 不继续整体推进 Round 02B。

Treatment 输出长度并不普遍更长，作者偏好不存在明显“篇幅更长即更好”的解释。

## 二、四项能力结论

### K1｜可计算风险系统

作者偏好：Treatment。

真正增量：不是泛泛写“有危险”，而是让多个独立暴露通道同时存在，角色只能局部消除风险；事情做成后仍留下可以继续发酵的后账。

Control 已会：代价、痕迹、盘查、暴露风险。

Treatment 增量：把这些风险组织成彼此独立、无法一次清零的结构。

处理：`继续验证`。

工作台位置：剧情规划 + 场景风险诊断。适合潜入、隐瞒、权谋、犯罪、调查、秘密行动等场景；不应默认对所有场景自动启用。

### K2｜外部约束改变表达形式

作者偏好：Treatment，但作者明确指出两版都有设计过密问题。

真正增量：公开环境不只是背景，而会改变人物能说多少、怎么说、用什么媒介、如何确认；“误读—纠错—确认”本身成为戏剧过程。

Control 已会：公开场合双层表达、暗号和动作传信。

Treatment 增量：加入确认成本和误读风险，避免“私聊内容套一层暗号皮”。

处理：`专项能力`。

工作台位置：对话 / 潜台词 / 高压社交场景的生成指导和诊断。后续必须加入“减法约束”：优先少量媒介，不要把每个动作都密码化。

### K3｜主动诱发式信息获取 / 反应测试

作者偏好：Treatment，但作者明确指出流程说明书感较强。

真正增量：先写清不同对象理论上可能出现的不同反应，再主动制造可区分刺激；实际反应只更新嫌疑，不直接当作定罪证据。

Control 已会：差异化信息、诱饵、二次验证，核心结构已经高度同构。

Treatment 增量：主要是“预期—实际反应校准”和“反应不是证据”的纪律，而不是新的剧情发动机。

处理：`改造后再测`。

工作台位置：调查 / 智斗 / 信息获取规划辅助。不要单独做成庞大 Skill；更适合压缩为几条轻量检查规则，并与信息差、验证、反证能力合并。

### K4｜可逆证据与竞争性解释

作者偏好：Treatment。

真正增量：同一条线索不是不断增加谜团，而是会在新证据出现后改变意义；同时阶段性真实结算旧问题，再留下新的未决问题。

Control 已会：多解释结构与悬念推进。

Treatment 增量：强化“旧线索语义重写 + 阶段结算”，而非无限反转。

处理：`继续验证`。

工作台位置：悬疑 / 信息控制 / 长篇伏笔规划 + 修订诊断。必须加入防副作用规则：禁止为了章末刺激额外制造廉价神秘钩子。

## 三、B09 到此收尾

B09 已完成它当前阶段的任务：

1. 验证原著蒸馏方法；
2. 从原著中筛出可迁移能力；
3. 用原创 Smoke Test 验证这些能力是否能改善实际剧情设计。

因此暂不整体启动 Round 02B。

后续按能力分流：

- K1 → 风险 / 场景因果专项；
- K2 → 对话 / 潜台词 / 社会约束专项；
- K3 → 调查 / 智斗 / 信息获取专项，先压缩改造；
- K4 → 悬念 / 信息控制 / 伏笔专项。

这些能力当前仍不直接写入 `04_写作知识库` 正式层；未来在各专项中与新的 GitHub 候选共同竞争、组合和再验证。

## 四、下一阶段原则

下一阶段不继续围绕 B09 扩张，而回到 AI-write 全局能力地图：

- 重新整理高价值 GitHub 上游；
- 按人物、情绪、对话、Reader Sim、Character Sim、Memory、Canon、连载、信息控制等能力分赛道；
