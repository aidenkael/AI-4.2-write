## 四、多来源选源核验

SP 通过 `book_id` 跨目录归并同一作品的全部候选来源，本次有 4 部为双/多来源，逐一核验：

### 1. 长安十二时辰（book_0035）— TXT + 合集 EPUB 双来源 ✓ 正确
- 候选 A（独立来源 TXT）：445,531 字符 / 31 章 / garbled 0 / PASS
- 候选 B（马伯庸作品合集拆分 EPUB）：465,687 字符 / 24 章 / garbled 0 / PASS
- **结论**：EPUB 比 TXT 多约 4.3%（更完整），两者均干净 → SP 按"完整性 > 格式"规则正确选中 **EPUB**。无跨源警告（长度差 < 65%）。双来源已正确归并到同一 book_id。

### 2. 诡秘之主（book_0032）— EPUB + TXT 双来源 ✓ 修复后正确（P1）
- 候选 A（EPUB）：4,527,770 字符 / **0 章** / garbled 0 / **REVIEW**（"未可靠识别章节边界"）
- 候选 B（TXT）：4,488,865 字符 / **1,392 章** / garbled 0 / **PASS**
- **修复前**：EPUB 仅比 TXT 多 0.86%，SP 因"完整性"严格大于而选 EPUB → 丢失全部章节、降为 REVIEW。
- **修复后（本次复测）**：近邻选源修正生效——长度差 ≤ 2% 且 EPUB 为 REVIEW/0 章、TXT 为 PASS/有章 → **改选 TXT**，最终 `PASS 诡秘之主: ...txt, chapters=1392`。`cross_warnings` 为空（修正说明在 notes，不触发 REVIEW 升级）。

### 3. 我不是戏神（book_0017）— EPUB + PDF 双来源 ✓ 正确（且验证 PDF 路径可用）
- 候选 A（EPUB）：2,582,843 字符 / 1,243 章 / garbled 0 / **REVIEW**（"正文长度仅为最长来源的 64%，可能不完整"）
- 候选 B（PDF）：4,019,792 字符 / 1,924 章 / garbled 0 / **PASS**（pypdf 提取成功）
- **结论**：PDF 比 EPUB 长 64% → EPUB 被标"可能不完整"合理；SP 正确选中**更完整的 PDF**。跨源警告（64% 差异）恰当，同时证明 **PDF 文本提取在装好 pypdf 后工作正常、输出干净**。

### 4. 庆余年（book_0015）— EPUB + TXT 双来源 ✓ 正确
- 候选 A（EPUB）：3,497,888 字符 / 7 章 / PASS
- 候选 B（TXT）：3,093,381 字符 / 85 章 / PASS
- **结论**：EPUB 比 TXT 长约 13%（真实完整性差距），选 EPUB 正确。EPUB 仅 7 章为该 epub 的卷级粗粒度结构，非缺陷；full.md 完整。
