# B09 Round 01 揭盲能力图结论

## 结论

Round 01 已完成正式 Runner、匿名化、双 Blind Judge、人工机制评审与揭盲。

本轮不产生“最佳 Skill”。结论单位是**能力与机制**：哪些应吸收、改造、合并、继续验证或舍弃。

## 当前最值得进入 Round 02 的能力

1. **可计算风险系统**：部分安全、残余风险、行为成本可被读者持续估算。
2. **外部约束改变表达形式**：环境压力不仅作为背景存在，还改变对话、动作与信息传递方式。
3. **主动诱发式信息获取 / 反应测试**：设计刺激，让不同身份因不同反应暴露信息。
4. **可逆证据与竞争性解释**：同一证据暂时支持多个解释，读者持续更新判断；必须阶段性结算，不能无限翻转。

以上均只是 Round 02 候选，尚不能进入正式知识库。

## 各方法的主要贡献

### D0 Baseline

证明最小提示也可能发现高价值机制；“外部约束改变表达形式”是本轮重要独立发现。后续所有 Skill Benchmark 应继续保留强基线，避免把模型本身能力误算成 Skill 增益。

### A｜oh-story adapted

在网文追读、信息控制、反转与钩子方面贡献突出；同时存在压缩纪律和模板化风险。适合吸收机制思想，不宜整体照搬。

### B｜ani-book evidence-first

最重要贡献是过程性证据纪律：fact / inference / hypothesis 分层、confidence、counter-evidence 等。其价值更像蒸馏基础设施，而不只是“多发现几张机制卡”。章节/证据定位仍需自动校验。

### C｜AI-write Candidate

Reader-causality、反证、迁移测试命题表现稳定，能把“作者操作 → 读者感知/判断 → 阅读效果”写得更完整；但输出偏长，存在成对回声和格式强于部分结论的风险，后续需要压缩。

## 合并 / 降级方向

- 力量—代价类：并入更高层的“能力—成本—后果系统”，避免重复卡片。
- 温情泄压 / 温情与权谋并置：合并后重构，要求低冲突场景产生关系、人物或后续剧情资产，不能只作为“让读者休息”。
- 程序承诺 / 制度认证：归入“程序、制度与证据博弈”能力簇。
- 有动机的信息交付：作为世界观 / 说明专项原则保留，不拔高为核心能力。
- 收益与历史债务绑定：原始模板过窄，需抽象后再验证。

## 证据边界

- P1、P2、P4、P5、P6 有用户正式人工判断。
- P3 无用户正式判断；Assistant 参考不得冒充用户偏好。如 P3 对后续关键取舍有决定性影响，再补人工评审。
- 双 Judge 使用同一模型，属于独立上下文重复评审，不是异构模型交叉验证。
- 本轮均为冻结窗口 sampled 结果，不外推为整本作品规律。

## 成本记录注意

Controller 揭盲汇报写有“单次运行 token 明细未留档”，但正式 Runner 完成汇报此前逐组提供过 token 数，并称 `run_metadata.json` 有记录。两者存在冲突。

在本地核对前，本项目控制层只采用以下安全表述：

> Round 01 已有总 token 与逐组运行时的 token 报告痕迹；是否完整保存在正式 metadata 中待本地复核。Round 02 必须把逐运行 token / 时长 / 输出字符作为强制可复核字段。
