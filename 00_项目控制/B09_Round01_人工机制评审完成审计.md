# B09 Round 01｜人工机制评审完成审计

## 结论

人工机制评审阶段完成，可以进入揭盲与来源贡献分析。

本轮人工环节已从“方案淘汰 / 强制二选一”修正为“能力发现、去重、改造与组合”。该修正符合 AI-write 的总体建设原则：最终评估对象是具体能力、机制和工作流，而不是选出唯一 GitHub Skill 冠军。

## 完成情况

- P1–P6 均完成机制层整理；
- P1、P2、P4、P5、P6 有用户正式判断；
- P3 没有用户正式作答，仅保留 Assistant 参考判断；
- 早期强制二选一结果仅作为历史观察，不作为淘汰依据；
- 全程未打开 blind map，未揭露 D0 / A / B / C 身份；
- 未按“胜场数”评选方案；
- 未把任何机制直接写入正式知识库。

## P3 限制

P3 缺少用户正式判断，因此揭盲后的人工证据汇总必须：

- 不把 P3 的 Assistant 参考判断计作用户选择；
- 不据此声称“用户偏好某来源方法”；
- 可将其作为低一级参考，与 Blind Judge 结果并列展示；
- 若 P3 对最终关键结论形成决定性影响，再单独补人工判断，而不是默认采用 Assistant 结论。

该限制不阻塞揭盲。

## 人工阶段形成的优先能力候选

当前值得在揭盲后继续追踪来源与跨题材验证的主要能力包括：

- 可计算风险系统；
- 外部约束改变表达形式；
- 主动诱发式信息获取 / 反应测试；
- 可逆证据与竞争性解释；
- 力量—代价记账（更适合作为“能力—成本—后果系统”的子机制）；
- 有动机的信息交付 / 戏剧化说明；
- 收益与历史债务绑定（需改造后验证）。

同时已识别出明显需要合并或降级的重复能力，如温情泄压类、部分监视/风险计价类、跨界物品验证类、章末截断钩、力量代价类等。

## 揭盲后的正确目标

揭盲不是为了宣布一个总冠军，而是回答：

1. 哪个来源方法稳定贡献了哪些高价值能力；
2. 哪些能力在多个方法中重复出现，应合并为 AI-write 自己的更高层机制；
3. 哪些方法擅长证据纪律、读者因果、网文追读、制度博弈、信息控制等不同维度；
4. 哪些能力值得进入 Round 02 跨题材迁移验证；
5. 哪些内容只是常识、漂亮术语、过窄模板或证据不稳，应舍弃。

只有揭盲后仍有价值、并在后续迁移测试中成立的机制，才进入正式知识库 / Skill 候选。
