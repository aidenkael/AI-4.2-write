## 3. 当前结论边界

G4-C 证明的是：

`Author Intent + Story State + Creation Brief + 少量 BKP Hit → 小 Context → 情境化创作方向`

这条最小链路可运行。

G4-C 不证明：

- BKP 已覆盖所有题材/情绪问题；
- 每个问题都应该跨书；
- 当前 Retrieval 是最终方案；
- Writer 正文质量已提升；
- Author Decision Loop 已验证。

无明确授权禁止：`reset / restore / clean / force push / rebase / merge`。

本地历史 dirty / untracked / stash 不得擅自清理、恢复或纳入提交；先识别内容，再决定处理方式。
