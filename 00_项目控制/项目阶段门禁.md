# AI-write 项目阶段门禁

> 当前 Gate、允许动作、退出条件和禁止范围的权威入口。更新时间：2026-08-13。

## 1. 当前 Gate

**单书蒸馏成品化：ACTIVE。**

G0–G4 已关闭。G5｜正文诊断与修订最小闭环：**PAUSED**，不作为当前主线。

## 2. 唯一目标

把现有 SourcePrepare + BookDistill 收成一个作者侧只有一次启动操作的单书流程：

`指定书名/book_id → SourcePrepare（如需）→ 两次全书 Discovery → 必要专项 Deep Dive → BKP Finalize → Retrieval 可发现 → 简短报告`

作者不需要理解内部命令、Pass、Schema、逐章 evidence 或 Deep Dive 文件。

## 3. 内部蒸馏规则

- SourcePrepare 只做输入标准化，不算文学蒸馏；
- **Discovery A：第 1 次全书蒸馏**，负责长篇运行/读者动力；MAP/FACT/INFERENCE/OBSERVATION/BOUNDARY 等 Base Scan 基础记录嵌入其中，不另算一次全书蒸馏；
- **Discovery B：第 2 次全书蒸馏**，负责 Reader/Page Craft；
- BookProfile 只负责导航与分配专项预算，不算额外蒸馏；
- Deep Dive 默认 0–2 个局部专项，按作品实际强项/疑点触发，不固定跑满；确有明显额外价值时可以超过 2 个，但需在报告中说明原因；
- Finalize 做总编辑式回源核证、去重、合并、补 scope/boundary/counterevidence/confidence，并封装 BKP；不算第三次全书蒸馏；
- 长书允许按章节/分块执行，不要求整书一次塞入模型；
- 单书 BKP 最高默认到 Work-specific Pattern，不自动升级为普遍写作规则。

统一口径：**1 次用户操作；2 次全书蒸馏；默认 0–2 次局部深挖；1 次最终收敛；1 个正式 BKP。**

## 4. 完成条件

当前 Gate 只有四个退出条件：

1. 存在一个明确的单书 Agent 入口，用户只需指定书名/book_id；
2. 入口能自动判断 SourcePrepare 是否已有 PASS，没有则运行，有 REVIEW/FAIL 则明确停止并报告；
3. Agent 能完成两次全书 Discovery、默认 0–2 个按需 Deep Dive、总编辑收敛和 BKP Finalize，并支持必要的中断恢复；
4. 用一部此前未蒸馏的新书真实跑通，最终 BKP 通过校验且 KnowledgeRetrieve 能发现。

不要求当前完成批量流水线、UI、跨书知识成熟度或正式写作。

## 5. 当前允许

- 直接复用/改造现有 SourcePrepare 与 BookDistill 脚本；
- 从已列入候选池的成熟项目借用单一深度管道、章节边界、断点恢复、token 预算、增量扫描等实现；
- 增加最小单书 orchestrator / runbook / 状态判断；
- 增加必要的失败报告与最小恢复能力；
- 调整 BookDistill SKILL，使一次操作可跑完；
- 选一部尚未蒸馏的新书做最终真实验收。

当前私人项目中，许可证只做 provenance 记录，不作为技术路线阻塞。

## 6. 当前禁止

- 不继续 G5 正文诊断实验；
- 不要求作者评价测试小说；
- 不批量蒸馏全部素材；
- 不重新发明 BookDistill 理论，只为“看起来更完整”；
- 不冻结所有作品相同的 Deep Dive 数量；
- 不升级 Retrieval/RAG/KG；
- 不开发 Writer、UI、大型数据库或多 Agent 平台；
- 不用单个失败案例直接扩张长期架构。

## 7. 作者交互

正常成功路径中，作者只需要启动一次并看最终结果。

只有以下情况允许中途询问：

- SourcePrepare `REVIEW/FAIL` 需要人工选源或补素材；
- 作品身份无法确定；
- 两个互斥的重大文学解释都会显著改变最终 BKP，且现有证据无法裁决。

普通 Deep Dive 选择、证据归并、重复项清理、BKP 封装均由后台完成。

## 8. Git 安全

无明确授权禁止：`reset / restore / clean / force push / rebase / merge`。

历史 local dirty / untracked / `stash@{0}` 先识别再处理；普通同步不建立无意义长期分支。

## 9. 防跑偏

> **当前不是继续研究“AI 怎么写小说”，而是先把“一本小说怎样经过两次互补全书蒸馏和必要深挖，稳定成为可长期调用的 BKP”做成简单可靠的成品。**
