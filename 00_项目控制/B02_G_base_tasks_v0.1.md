# B02-G 三个中性 Base Task（v0.1 冻结）

> 状态：已冻结。三个任务的中性 base prompt 相同地提供给 D0 / G1 / G2；G1 / G2 仅在 base 之后追加各自最小机制注入块。
> 统一输出要求：中文小说正文；目标 900–1200 中文字；只输出正文，不输出分析、提纲、说明或创作理由；不得改变故事前提。

## T1 爱情关系

```text
写一段中文小说正文，完整呈现以下场景。只输出正文本身。

【场景】
一对已有稳定感情基础的情侣。女方看到男方与一位更年轻、漂亮、互动自然的女性交谈。她在意这件事，但自尊较强，不愿直接承认。男方最初没有意识到她真正介意什么。

【输出要求】
- 目标 900–1200 中文字；
- 只输出小说正文，不输出分析、提纲、说明或创作理由；
- 不得改变上述故事前提；
- 禁止直接使用“吃醋、嫉妒、酸、醋意”等直接情绪词语。
```
