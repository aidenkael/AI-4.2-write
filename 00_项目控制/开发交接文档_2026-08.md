# Go Write 开发交接文档

> 日期：2026-08-22 | 用途：暂停开发时的快速恢复参考

## 1. 项目定位

Go Write 是面向作者的 AI 写作工作台，不是 Agent 调度平台。

## 2. 当前架构

```
作者
→ Go Write（准备任务、管理状态）
→ Qoder Desktop /gowrite（AI 执行）
→ 返回结果
→ Go Write 保存
```

**不要把以下三者视为同一种东西：**

| 组件 | 定位 |
|---|---|
| Qoder Desktop /gowrite | 当前作者执行入口，日常创作唯一 AI 路径 |
| Qoder CLI | 保留的后台能力，不作为作者隐藏调用路径 |
| DeepSeek Harness | 保留的开发/测试能力，不属于普通作者流程 |
