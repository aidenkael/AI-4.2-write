# 03_作品工程

用户真正写小说的地方。每一部真实作品在此创建独立目录。

## 放什么

- 作者的原创小说作品
- 每部作品的设定、人物、规划、正文、资料
- 工作台状态（Story State、authority、decision history）

## 不放什么

- 参考原著（→ 01_原始素材）
- 参考作品知识 BKP（→ 02_原著蒸馏）
- 跨书通用知识（→ 04_写作知识库）
- 临时运行产物（→ 06_工作区）

## 目录结构

每部作品直接创建：

```
03_作品工程/
└── <作品名>/
    ├── README.md
    ├── 01_设定与人物/    ← 作者可读的设定、人物、关系、世界信息
    ├── 02_规划/          ← StoryPlan / 大纲 / 阶段计划 / 作者确认方向
    ├── 03_正文/          ← 作者真正接受并保留的小说正文
    ├── 04_资料与灵感/    ← 只属于本项目的想法、调查、素材和灵感
    └── _工作台状态/      ← Agent/runtime 使用的 Story State 等
```

## 重要规则

- **01_设定与人物**：作者可读的设定信息
- **02_规划**：StoryPlan / 大纲 / 阶段计划
- **03_正文**：作者真正接受的正文。未 author-accepted 的生成稿不得冒充正式正文
- **04_资料与灵感**：只属于本项目的素材
- **_工作台状态**：Story State、authority、decision history 等

## _工作台状态 不长期保存

- Context package（可重建 derivative）
- recent prose window
- 临时 Brief
- 模型缓存

## Agent 操作规则

- 不预建十几个细目录（人物卡/关系图/事件/场景/伏笔/时间线等）
- 真实需求出现再创建
- 不创建示例作品
